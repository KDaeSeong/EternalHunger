# 문명 아카이브 일손 배치 비교

부족 화면의 직업 배치 위에서 출발 직업과 도착 직업을 골라 한 명을 옮기는 손익을 비교한다. 미배치 인원도 출발지로 선택할 수 있다. 비교 자체는 무료 조회이며 배치·재고·행동력·날짜·기록·저장을 바꾸지 않는다.

표는 **직업 생산**, **정산 후 재고**, **운영**을 구분한다. 현재와 변경 후 값, 부호가 있는 차이와 단위를 함께 표시한다. 기존에 허용된 소수 재고와 연구·제도 진척도는 원래 값을 보존한다. 식량 부족이나 자재 소비의 증가가 유리하다는 뜻은 아니므로 증감 부호를 일괄적인 좋음·나쁨 판정으로 사용하지 않는다.

## 실제 계산 범위

기존 경제 처리 구간을 두 가상 상태에서 공유 실행한다. 한쪽은 현재 배치, 다른 쪽은 한 명을 실제 편집한 배치이다. 확률 수확이나 직업 설명의 최대치를 정산 결과처럼 표시하지 않는다.

1. 실제 자동·미배치 일손 재배치를 반영한다. 직접 고정한 직업의 인원은 유지한다.
2. 직업 생산 후 사업 착수 자재를 투입하고 남은 작업량 안에서 건설한다. 같은 정산에서 발생한 완공 보상도 반영한다.
3. 공교육이 기존 종이를 소비하고 사회 제도를 진전시킨다. 남은 기록대 인원이 연구하며 실제 남은 진척량으로 제한한다.
4. 공동 배식과 기존 성장·가구 처리를 거친 뒤 남은 재료로 가공한다. 가공은 실제 일손·재료·목표 비축·안전한 수량 한도를 따른다. 이번에 만든 종이를 앞선 교육 단계에 소급하여 쓰지 않는다.

일일 비교는 자동 배치와 현재 비축의 저녁 식사·연료 준비 후, 다음 아침의 공동 경제를 계산한다. 현재 생존자와 후계·은퇴 가구를 고정한다. 미래 밤 피해·사망·새 날씨·후계 인계와 시설 자동 연구·제도는 제외한다. 따라서 개인의 밤 생존 결과를 보장하는 예측이 아니며 화면에 이 범위를 함께 표시한다.

연간 비교는 기존 달력 진행과 전체 인구 조사를 사용한다. 증가한 연도를 생산 주기로 쓰고 활동 인물·후계·은퇴자까지 기존 전체 배식에 포함한다. 경제 뒤에 실행되는 시설 자동 연구·제도와 연간 세대 인계는 제외한다.

비교는 부족 탭이 열린 때 선택한 한 쌍만 계산한다. 전체 하루·한 해의 확률 사건을 재실행하거나 저장 상태에 가상 결과를 쓰지 않는다. 정규화 과정의 새 식별자·난수 경로는 조회에서만 우회하며 기존 실제 행동의 호출 경로는 유지한다.

## 적용과 보호

**1명 옮기기**를 눌러야 배치가 바뀐다. 두 직업의 감소·증가를 먼저 전부 검증하고 한 번에 확정한다. 적용되지 않은 비교만으로 자원을 지급하지 않는다. 출발지에 인원이 없거나 도착 직업이 잠긴 경우 부분적으로 인원을 빼지 않는다.

직접 조정한 출발·도착 직업은 그 직업 전체의 자동 인원이 수동으로 고정된다. 기존 ± 버튼과 같은 규칙이며 운영 방침은 바꾸지 않는다. 나머지 자동 일손은 실제 다음 정산 규칙에 따라 다시 배분되므로 표에서 계산한 배치도 펼쳐 볼 수 있다. 편집은 행동력과 게임 시간을 소비하지 않지만 실제 편집 기록과 갱신 시각은 남긴다.

보기 전용 탭은 준비된 상태를 비교할 수 있다. 적용은 현재 계정·런·대원·탭·모드·저장 쓰기 권한과 최신 선택을 다시 확인한다. 불러오기와 계정·런 전환은 비교를 초기화하고, 같은 값으로 초기화해도 이전 콜백을 재사용하지 않는다. 종료·저장 충돌·비동기 저장 작업 중에는 적용하지 않는다.

## 검증과 남은 확인

일반 검사는 현재 추적 소스와 새 고정 입력만 사용한다. 사설 `.local` 원본이나 과거 경기 결과를 필요로 하지 않는다. `npm run check:primitive-archive:worker-allocation`은 경제 비교와 화면 콜백·정적 렌더 검사를 실행하며 전체 문명 아카이브 검사에도 포함된다.

원본 보존 대조는 별도의 일회성 검사이다. 변경 전 실제 소스와 동일한 공통 입력으로 기존 직업 편집·자동 배치·경제 정산·일일 및 연간 행동의 결과, 기록, 난수 순서를 비교한다. 이 대조를 현재 소스만 사용하는 일반 검사와 혼동하지 않는다.

제어한 콜백과 정적 렌더 검사는 실제 탑재 수명주기·브라우저 키보드·좁은 화면 배치·실제 두 탭 쓰기 권한 검증을 대신하지 않는다. 현재 실제 화면 조작은 중단 상태이며 해당 인수와 사람의 플레이 평가는 남아 있다. 이 변경은 경제 균형이나 전체 시대 운영의 인수 완료를 뜻하지 않는다.
