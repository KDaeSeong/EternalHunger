# 실험체 상태의 실제 전투 연결

기준: 2026-09-05 사용자 제공 실험체 참고자료. 현재 서비스 중인 원작 최신판의 모든 상태·개별 기술을 복제했다는 의미가 아니다. 전체 목표 G2.3 중 기본 상태 구분을 구현한 기록이다.

후속 범위 안내: 독립 시전은 `character-casting-verification.md`, 실제 좌표·사거리·시야와 최신 전체 검사/브라우저 재경기는 `combat-spatial-verification.md`에서 완료한 범위를 확인한다. 아래의 당시 미완료 목록을 현재 남은 작업으로 그대로 복사하지 않는다. 나머지 상태·면역·저항 등은 여전히 미완료다.

그 이후 그룹 면역·저지 불가·정화·지속 시간 저항 연결과 소수점 경계 검증은 `status-protection-verification.md`를 따른다. 강제 보행 등 나머지 CC 행동과 시야 상태는 아직 미완료다.

## 적용한 구분

| 상태 | 자발 이동 | 기본 공격 | 캐릭터·전술·무기 스킬 | 표적·피해 |
| --- | --- | --- | --- | --- |
| 기절 / 기존 에어본 | 불가 | 불가 | 불가 | 피격 가능 |
| 속박 | 불가 | 가능 | 제자리 기술 가능, 이동 포함 기술 제한 | 피격 가능 |
| 침묵 | 가능 | 가능 | 불가 | 피격 가능 |
| 무적 | 가능 | 가능 | 가능 | 표적 지정·기절 적용 가능, 기본/스킬/고정 피해는 0 |
| 대상 지정 불가 | 가능 | 가능 | 가능 | 새 표적 선택·새 상태 적용 제외, 기존 지속 피해는 유지 |
| 실명 | 가능 | 빗나감 | 일반 스킬 피해 가능 | 자신이 가하는 기본 공격 피해만 0 |
| 회피 | 가능 | 가능 | 가능 | 들어오는 기본 공격 피해만 0 |

표는 다른 중첩 상태가 없을 때의 상태 자체 의미다. 예를 들어 속박+침묵이면 이동·스킬 모두 제한된다. 속박은 모든 행동 불가로 처리하지 않는다.

`includesMovement: true`인 캐릭터 기술은 속박 중 발동·쿨다운 소비를 하지 않는다. 블링크·붉은 폭풍은 기존 전술 카탈로그의 이동 기술 설명에 따라 제한했다. 모든 원작 무기/캐릭터 기술의 이동 여부를 분류한 것은 아니다. 기존 기술에 새로운 CC나 피해 수치를 임의 부여하지 않았다.

## 실제 실행 경로

- 공통 상태 판정: `statusEffectDefinitions.js`, `statusEffectSelectors.js`, `statusLogic.js`. 영문 별칭을 한국어 상태로 정규화하고, 명시적으로 만료된 효과는 행동·능력치·면역·보호막·중첩 수에서 제외한다. 지속 시간이 없는 기존 효과는 영구 효과로 유지한다.
- 단일 공격·팀 집중 공격·캐릭터 기술 표적/지원/광역: 대상 지정 불가를 후보에서 제외하고 피해 적용 시 다시 검사한다. 무적을 표적 지정 불가로 바꾸지 않는다.
- 실명/회피/무적: HP 감소·보호막 소모·흡혈·기여도 없이 차단한다. 빗나간 공격은 치명타 난수를 소비하지 않는다. 기본 공격 실패 이유를 피해 사건과 한국어 전투 로그에 남긴다.
- 침묵: 일반 공격을 보존하고 캐릭터 기술, 전술 발동, 무기 후속 기술을 제한한다. 이미 있던 보호막은 침묵 상태에서도 작동한다.
- 이동: 일반 이동, 금지구역 이탈, 교전 회피, 빈사 도주, 추격, 긴급 CNOT 이동에 상태를 연결한다. 실패한 회피는 임시 AI 회복/교전 보호를 얻지 않는다. 속박+외부 넉백의 경우 밀려나는 것은 유지한다.
- 상태 적용: 대상 지정 불가 중 새 효과는 `untargetable` 사유로 거부한다. 사건과 상태 적용 로그에 이유를 남긴다. 기존 DOT는 제거하지 않는다.
- 지속 피해: 무적이 남아 있는 시간만 보호한다. DOT 5초와 무적 2초를 한 번에 계산하거나 1초씩 계산해도 피해는 3초분이다.
- 금지구역 지속 피해: 공유 시계의 구간 시작 상태로 보호 시간을 계산한다. 먼저 만료된 구간 끝 상태를 사용해 마지막 보호 1초를 잃지 않는다. 무적은 목걸이 타이머 정지가 아니므로 폭발 사망은 계속 가능하다. 경직의 타이머 정지는 아직 구현하지 않았다.
- 사냥의 추상 피격 경로에도 무적/대상 지정 불가를 반영했으나, 사냥 전체를 기본 공격·스킬 교환으로 바꾼 것은 아니다.

## 통제 검사

`client/scripts/check-combat-status.mjs`, 실행: `cmd /c npm run check:combat-status`.

23개 통과. 순수 이름/수식 검사뿐 아니라 실제 단일 교전, 팀 교전, 기술 선택/지원/광역 실행기, 전술 방어, 무기 기술, 이동/도주, 상태 경과, 금지구역 실행기를 호출한다.

대표 결과:

- 공격력 100, 방어력 0, 제자리 기술 피해 40: 속박된 공격자의 표적 HP는 1,000→860, 침묵은 1,000→900, 기절은 1,000 유지.
- 속박된 공격자의 이동 기술 쿨다운은 그대로이며 제자리 기술만 사용한다.
- 실명+흡혈 공격자의 기본 공격은 보호막을 소모하거나 회복하지 않는다. 별도 일반 스킬 40만 보호막에서 차감한다.
- 대상 지정 불가인 HP 1 실험체는 팀 집중 공격이나 최저 HP 기술 표적에 선택되지 않는다. 새 기절/보호막 적용은 실패하며 기존 중독은 지속한다.
- 무적은 기절을 막지 않는다. 무적 중 기본/스킬/고정 피해는 0이며 보호막도 남는다.
- 2초 기절은 실제 상태 처리 1초 후 공격 불가, 2초 후 공격 가능.
- 속박 중 회피/강제 도주 요청은 이동·전술 쿨다운·AI 보호를 얻지 않는다. 속박된 추격자도 이동하지 않는다.
- 5초간 금지구역 피해, 무적 또는 대상 지정 불가 2초: HP 1,000→850. 한 번에 처리한 결과와 1초씩 처리한 결과가 일치한다. 보호 없는 대조군의 1초 피해도 검사하여 조기 반환만으로 통과하지 않게 했다.
- 속박은 긴급 CNOT 이동을 막고 기절은 CNOT/휴대용 안전지대의 능동 발동을 모두 막는다.

검사 작성 중 `치유의 바람`을 즉시 회복으로 가정한 기대값을 기존 실제 재생 효과에 맞게 정정했다. 또한 금지구역 검사에 최종 압박 조건이 빠져 처리기를 건너뛰던 부분을 대조군과 함께 수정했다. 이 두 초기 실패를 통과 증거에 포함하지 않는다.

## 미완료 / 다음 작업

후속 변경(2026-09-05): 기본 공격 간격, 소수점 상태 시간/해제, 시전·후딜 예약 준수는 `combat-timing-verification.md` 단계에서 구현했다. 아래 실전 수치는 그 변경 전 상태 구현 버전의 증거다. 별도 스킬 시전 실행 및 거리 모델은 여전히 남아 있다.

- 공격 속도에 따른 기본 공격 간격, 기술 시전/후딜과의 시간 배분, 실제 거리 기반 행동. 기존 팀 라운드 예약 시간을 공격 속도 구현으로 간주하지 않는다.
- 개별 기술의 이동 포함 여부 전수 분류, 원작 스킬/CC 데이터와 편집 화면 연결. 현재는 명시된 입력의 처리 기반이다.
- 경직·공포·도발·매혹·수면·속박 연계 강제 보행, 실명 외 시야 상태, 제압·정신 집중과 취소/면역 세분화.
