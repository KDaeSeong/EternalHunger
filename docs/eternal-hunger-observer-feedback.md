## HF1 구현 범위와 검증 경계

- 원본 PNG는 변경하지 않았다. 표시용 좌표는 그 이미지의 픽셀 좌표에서 한 번만 변환한다. 이전 섬 중심 방향 보정 좌표는 기본 지도의 캐릭터/금지구역 표시에 사용하지 않는다.
- 금지구역의 기존 축소 다각형을 참조 이미지의 표시용 경계로 교체했다. 이 경계는 수작업으로 단순화한 영역이며 원작의 충돌 지형이나 모든 골목의 통행 자료가 아니다.
- 기존 이동 시간·수색 면적 계산과 이동 가능 연결은 이 표시 수정에서 바꾸지 않았다. 표시 위치를 실제 전투 좌표로 가장하지 않으며 지도 아래에 지역 단위 요약임을 명시한다. 원작 통행 연결의 별도 정합성 감사는 아직 하지 않았다.
- 개별 아이콘이 좁은 지역에 들어가지 않으면 팀별로 묶는다. 읽을 수 있는 크기로 팀 전부를 넣을 수 없는 경우 해당 지역의 팀 수/인원을 표시하고 눌러 전체 참가자·팀·HP를 확인한다. 생존자를 삭제하거나 이웃 지역으로 옮겨 그리지 않는다.
- 기존 검사의 `referenceMapAligned: true`는 이미지 크기/설정값 확인만으로 원본 정합성을 주장하던 출력이었다. 이를 제거하고 레거시 모델 경계 검사와 참조 지도 검사를 구분했다.
- 새 검사: 21개 지역 × 6개 인원 조건(1/3/9/24명 스쿼드, 24명 개인전, 36명 초과 입력), 표시 전체의 지역 포함·지역명 회피·모든 참가자 보존·최소 크기·입력 불변성과 이미지 좌표 왕복. 시각적 원본 충실도와 재미를 자동 합격 처리하지 않는다.

## 2026-09-24 HF1 이동 연결 조사 착수

- [공식 11.0 패치노트](https://playeternalreturn.com/posts/news/3530?hl=ko-KR)는 바지선을 항구와 공장 사이의 21번째 지역으로 설명하며 두 인접 지역의 지형 조정을 명시한다. 현 내장 지도의 바지선–항구/공장 연결과는 맞지만, 이 설명이 나머지 전체 연결이나 개별 장치 위치를 증명하지는 않는다.
- 내장 지도는 기본 도로 목록과 구역별 하이퍼루프 표시 외에 `hyperloopDeviceZoneId: 'lab'`를 따로 지정한다. 실제 관전 요약의 12개 하이퍼루프는 이 합친 목록이다. 참조 PNG의 장치 아이콘 개수/픽셀 위치만으로 이 별도 장치의 의도나 각 지역 귀속을 확정하지 않는다.
- 사용자 지도의 명시적 연결은 `mapGraphRuntime.buildBaseZoneGraph`에서 우선하지만, `routePlanBuilderRuntime.buildRouteConnectionInfo`는 루미아형 지역 ID가 충분하면 기본 연결을 다시 합치는 별도 경로다. 또한 `getHyperloopZoneIds`는 기본 시설 목록을 합친다. **이 불일치 후보는 다음 재현 검사에서 경로 추천/실제 이동/호환 fallback을 대조할 대상**이며, 이번에는 회귀를 실행하거나 전체 경기의 결함 원인으로 확정하지 않았다.

전체 통행 정합성과 사람의 가독성 합격은 계속 미완료다. 최신 계측의 성능/메모리 근거는 `observer-frame-yield-verification.md`에서 따로 관리한다.

### 같은 날 후속: 사용자 지도 불일치 재현·수정

위 후보를 루미아 지역 ID/단방향 길/하이퍼루프 명시 해제의 별도 입력으로 재현했다. 수정 전 17개 중 14개 실패였고, 실제 이동 그래프를 경로 추천에서도 사용하며 명시한 장치 해제를 지역 정보 보강에서도 보존한 뒤 17/17을 통과했다. 기존 내장 지도 21지역/유효 장치 12개·저장 입력 경기 결과는 유지된다. `f7f6d4bc…` 실제 제품 저장·새로고침·원본 x32/재경기 x16의 8,323사건·최종 상태·종료 일치, 원본 1건 보존도 확인했다. 자세한 근거와 변경 제외 범위는 `map-navigation-contract-verification.md`를 따른다. **원작 전체 통행/시설 고증과 사람의 가독성 합격은 여전히 미완료**이며 원 마커스 경기 원인이라고 주장하지 않는다.

현재 인간 평가를 **0건**으로 적은 과거 문서 절은 당시의 자동 검사 기록이다. 현재는 평가를 수신했고 HF1–HF7의 수정 및 재검증을 진행 중이다. 전체 목표는 미완료다.
