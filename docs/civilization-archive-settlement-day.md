# 문명 아카이브: 정착 운영으로 하루 진행

## 변경 범위

개인 행동을 모두 수행하지 않고 남은 행동력(AP)을 포기하여 기존 하루 정산으로 넘어가는 명시적인 명령을 추가했다. 개인 입력 중심 진행에서 공동체의 하루 운영으로 넘어가는 제한된 전환이다. 후기 시대의 제도 전체, 시대별 시간 단위 변경, 문명 아카이브 전체 목표의 완료를 뜻하지 않는다.

새 버튼은 현재 목표·밤 대비 패널의 정착 운영 요약에 있으며 기능 탭보다 앞에 표시된다. 운영 상세를 접어도 위험 안내와 버튼이 함께 보인다. 버튼은 포기할 AP를 표시하고, 접근성 설명도 같은 위험 안내에 연결한다.

## 표시 조건과 위험

다음 조건을 모두 충족해야 정착 운영 명령을 표시한다.

- 런이 종료되지 않았고 생존 대원이 한 명 이상 있다.
- `SETTLEMENT`(정착), `FOOD_STORAGE`(식량 저장) 연구를 모두 완료했다.
- 거처 수준이 1 이상, 부족 인구가 1 이상, 사기가 0보다 크다.
- 남은 AP가 유한한 양수이다.

선택한 행동 대원이 사망했어도 다른 생존 대원이 있으면 이용할 수 있다. 식량·연료가 일정량 이상이라는 추가 조건은 없다. 비축이 부족한 상태도 진행할 수 있으며, 안내문은 현재 비축으로 밤을 정산하고 다음 날 생산을 앞당겨 사용하지 않는다는 점과 식량·연료·보온 부족에 따른 피해·사망 가능성을 밝힌다. 종료되거나 진행이 차단된 패널에서는 명령을 표시하지 않는다.

## 정산 의미

현재 남은 AP를 0으로 만들고 `advanceDay`를 한 번 호출한다. 채집·사냥·제작 등 개인 행동을 대신 실행하거나 개인 행동 보상을 생성하지 않는다. 기존 하루 경계의 다음 처리를 재사용한다.

1. 정착지의 일손 배치를 재검토한다. 명시적으로 수동 배치한 직업은 기존 규칙대로 보존한다.
2. 현재의 실제 비축을 사용해 저녁 배식과 연료 보충을 처리한 뒤, 밤의 체온·허기·추위 피해와 사망을 정산한다.
3. 기존 날짜·AP 갱신과 계보 처리를 거쳐 다음 아침의 부족 생산·배식, 사업, 자동 연구·사회 제도 진행을 처리한다. 각 처리의 해금 조건과 순서는 기존 하루 경계에 따른다.

이번 밤에 다음 아침 생산분을 빌려 쓰지 않으며, 밤에 전멸하는 결과도 기존 규칙을 따른다. 클릭 당시의 `runId`, `day`, `ap`, `updatedAt`을 실제 최신 상태와 비교한다. 이미 처리한 버튼을 다시 누르거나 다른 상태에서 남은 오래된 콜백을 실행해도 하루를 추가로 정산하지 않는다.

기존 빠른 행동 머리글의 **하루 자동 운영** 버튼은 유지한다. 이 버튼은 기존 `canAct` 조건과 `runAutoDayAction`을 사용해 개인 행동을 자동으로 수행하는 경로이다. 새 정착 운영 명령은 별도 경로이다.

## 저장과 쓰기 권한

새 명령도 기존 `applyAction`을 통과한다. 화면 초기화, 현재 소유자 확인, 이 탭의 쓰기 권한 확보가 끝나야 사용할 수 있다. 소유자가 아직 확인되지 않았거나 다른 탭이 쓰기 권한을 보유한 경우, 서버 저장·불러오기 중인 경우, 상점 혜택을 적용하거나 새 런을 준비 중인 경우에는 진행하지 않는다.

쓰기 권한을 유지한 탭에서 기록 상태가 `conflict`, `unavailable`, `corrupt`라는 이유만으로 메모리상의 게임 진행을 일괄 차단하지 않는다. `ready`와 `exclusive`를 비롯한 기존 조건이 충족되면 메모리 진행은 가능하며, 저장 계층은 기존 충돌·기록 보호 정책을 따른다. 다른 탭의 쓰기 권한을 빼앗거나 충돌한 디스크 기록을 강제로 덮어쓰는 기능을 추가하지 않았다. 메모리 진행과 디스크 저장 성공은 별도로 판단해야 한다.
