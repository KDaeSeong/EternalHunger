지도 계약 17개는 방향, 비활성 장치, 점수 계산과 실제 이동, 저장 재경기, 난수 불변성을 확인한다. 외부 전체 지도 비교와 별개다. 이번에 확인한 패치 문구는 43연결의 전수 목록이나 12장치의 전수 위치 자료가 아니다. 공식 지도 이미지 두 개는 403으로 내용을 확인하지 못했다. 이를 bot 차단이나 이미지 확인 성공으로 표시하지 않았다.

다음은 같은 기준 시즌의 전체 원작 지도/장치 목록을 확보해 각 도로의 양방향 여부와 출발 장치를 행별로 대조하는 일이다. 최신 시즌으로 옮길 경우에는 지도·재료·규칙·저장 재경기 버전을 함께 명시해야 한다. 이번 조사로 확정하지 못한 연결을 임의로 추가/삭제하지 않았다.
