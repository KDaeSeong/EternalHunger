## 제품 정의와 범위

원하는 캐릭터로 팀을 편성하면 각 팀이 파밍·제작·합류·교전·후퇴하며 자율 생존하고, 관전자가 승패의 이유를 이해하여 다시 편성하고 경기하고 싶어지는 시뮬레이터.

핵심 경기는 로그인과 계정 서버에 의존하지 않는다. 기존 웹 기술과 기능은 보존하되 다른 게임, 포털, 계정·재화 확장은 하지 않는다. 원작의 최신 수치나 실시간 액션 전체 복제는 목표가 아니다. 팀 생존과 성장의 인과관계를 우선한다.

## 공통 완료 조건

- 사망자 재행동, 재료 없는 제작, 보상 중복, 시간 역전, 계정 서버 의존 회귀가 없어야 한다.
- 자동 검사는 기능 증거다. 빌드 통과나 이벤트 수를 재미·밸런스 합격으로 계산하지 않는다.
- 통제된 성장 검사와 실전 경기는 분리한다. 실전에서 조기 탈락한 참가자에게 장비 완성을 보장하지 않는다.
- 목표 장비 완성률, 합류 성공률, 반복 왕복, 후퇴 반복, 종료 원인을 실제 기록한다. 목표 수치는 기준선 관측 후 근거와 함께 정하며, 테스트에 맞추기 위해 목표를 낮추지 않는다.
- 기존 변경 및 다른 프로젝트 파일은 보존한다. 원격 배포·계정 변경·새 포털 기능은 이 목표의 작업으로 추정하지 않는다.

## 작업 순서

1. G1 성장 계획과 소비 경로를 구현하고 실제 실행기를 사용한 기준선을 만든다.
2. G2 팀 합류/교전과 G3 자원·경기 종료 흐름을 연결한다.
3. G4 관전 화면을 실제 상태에 연결하고 이해 가능한 근거를 제공한다.
4. G5 재현·재편성·비교 흐름 및 여러 조건 검사를 완료한다.
5. 실제 사용자 평가를 받아 남은 문제를 수정한다. 평가 전에는 전체 목표를 완료 처리하지 않는다.

사용자가 2026-09-05 제공한 실험체 참고자료에 따라, G5.2 전략 선택을 늘리기 전에 G2.3의 전투 인과관계를 보강한다. 원작 최신판 전체 복제로 범위를 바꾸지는 않으며, 미확인 원작 수식과 이 프로젝트의 명시적 규칙을 구분한다. 앞선 버전의 완료 증거는 보존하되 전투 규칙이 바뀐 뒤의 결과 분포나 재경기 증거로 재사용하지 않는다.
