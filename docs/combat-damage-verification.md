## 2026-10-04 후속: 체력 비례 피해의 명시적 단위

설명 파서가 인식한 최대 체력 `0.2%`를 편집·저장 정규화가 과거 비율 표현으로 오인하여 `20%`로 바꾸는 오류를 실제 타격으로 재현했다. HP/최대 HP 5,000·방어 0인 대상에게 독립 기대값은 10인데 수정 전에는 1,000 피해였다. 수정 후 설명 변환→편집→JSON 정의→AI의 실제 피해 미리보기→실제 교전 타격에서 모두 10으로 일치했다. 이는 현재 코드의 재현이며 JSON이 없는 과거 토머스 비컴 경기의 3,446 원피해 원인으로 확정하지 않는다. AI 평가와 실제 실행은 같은 피해 함수를 사용한다.

새 정의는 `hpDamagePercentUnit: 'percent'`로 네 체력 비례 피해 배열의 단위를 백분율 수치로 명시한다. `0.2`는 0.2%, `20`은 20%다. 표식이 없는 기존 정의는 과거 경계(양수 0.25 이하를 비율, 그보다 큰 값은 백분율 수치)를 유지한다. 편집/컴파일에서 기존 배열을 한 번 정규화한 뒤 표식을 붙이고, 이후 편집·저장·재로드에서는 다시 확대하지 않는다. 새 설명의 명시적 `%`만 새 단위로 해석하고 관련 없는 기존 배열의 의미는 보존한다. 계수·방어·치명타·시간·난수·궁극기 사냥 금지·보상 규칙은 변경하지 않았다.

## 2026-10-04 후속: 사냥 무기 추가 타격의 흡혈

실제 사냥은 기본 타격과 무기 추가 타격에 같은 피해 실행기를 사용하지만, 후속 무기 호출에 `targetKind`가 전달되지 않았다. 무기 실행기에서도 해당 값을 공통 흡혈 함수에 넘기지 않아, 야생동물 대상의 추가 타격만 실험체 대상 기본값으로 회복했다. 두 연결을 보완하여 일반 동물과 알파·오메가·위클라인의 추가 타격에도 기존 야생동물 60% 회복 계수를 적용한다. 피해량·발동 확률·난수 소비·쿨다운·보상·궁극기 사용 정책은 변경하지 않았다. 무기 자체의 별도 회복 효과를 이 공통 흡혈과 혼동하지 않는다.

현재 입력을 사용하는 실제 실행기 검사에서 원래 코드의 무기 HP 피해 6·모든 피해 흡혈 50%가 HP 3을 회복하여 기대값 1과 달랐다. 무기 함수만 수정하면 공유 타격의 두 피해 묶음 합계 회복이 여전히 39 대 37로 실패했고, 호출자의 대상 구분까지 전달한 뒤 일치했다. 기대값은 기존 회복 수정자의 **각 피해 묶음별 내림**을 유지한다. 초과 피해는 실제 HP 감소 4만 사용하여 1 회복, 전량 보호막은 0 회복이며 실험체/미지정 대상의 기존 회복량은 그대로다.

## 기준과 확인되지 않은 부분

사용자가 이 대화에 제공한 능력치·피해 공식·상태 설명을 설계 참고자료로 삼았다. 기본 공격은 공격력, 스킬은 정의된 기본 피해와 계수, 방어 관통은 비율 후 고정 순서, 기본 치명타 배율은 1.75로 구분한다.

붙여넣은 기본 공격식의 `피해 증가 - 피해 감소`에는 중립 배율 1이 없고, 최종 피해 비율도 보너스인지 전체 배율인지 불명확하다. 이번 프로젝트 계약은 보너스 0일 때 1배인 `1 + 보너스`로 명시했다. 별도 공식 자료 검색에서 이 모든 식과 예외를 확정하는 개발사 원문은 확보하지 못했다. 최신 원작과 완전 일치한다고 표시하지 않는다.

관통 후 방어력의 하한은 이 시뮬레이터에서 0으로 정했다. 증폭 하한은 0.1, 스킬 피해 감소는 0~100%, 최종 고정 추가는 비율 계산 뒤이며 원피해가 0인 지원 스킬에 피해를 새로 만들지 않는다. 고정 피해는 방어력·증감·치명타를 통과하지 않고 보호막 처리 대상이다. 이 경계 규칙 역시 프로젝트의 명시적 계약이며, 원작의 미확인 예외로 추정하지 않는다.

## 실제 변경

- `combatDamageRuntime.js`: 장착 슬롯별 능력치 합산, 공격력·방어력·관통·피해 종류·치명타·최종 추가 계산. 아이템의 기존 스증 단위는 100배로 변환하고, 비율은 캐릭터 데이터에서 0.1=10%로 사용한다. 장착된 낮은 등급 무기 대신 가방의 높은 등급 무기를 몰래 더하지 않는다.
- 맞춤형 능력치는 무기 이름이 아니라 추가 공격력(장비 및 기본 성장분을 제외한 적용 보너스)과 스킬 증폭을 비교한다. 동률은 공격력, 스증 선택 시 2배 지급한다.
- 신규 비율·관통 필드를 실험체 정규화에서 보존한다. 기존의 모든 능력치 하한 1 처리를 제거하고 필드별 하한을 사용한다. 0%가 100%가 되거나 공속 0.72가 1이 되지 않는다.
- 실제 PvP는 참가자별 방향성 타격을 계산한다. 교전 우세자 추첨·날짜 피해 보정·확률 마무리로 HP를 지우는 경로를 사용하지 않는다. 팀 집중 공격·지원·행동 비용은 보존하며, 1:1에서도 먼저 죽은 실험체는 반격하지 않는다.
- 캐릭터 스킬의 장비 스증 및 공격력 계수를 합산하고 대상별 방어를 적용한다. 기본 공격 피해형으로 명시된 강화는 부모 공격의 치명타 결과를 공유한다. AI 대상 평가가 난수를 추가 소비하지 않는다.
- 전술 공격의 추가 피해와 무기 스킬 후속 피해도 스킬 피해로 방어·보호막을 통과한다. 무기 스킬의 기존 발동 확률과 원피해 산출 계수는 아직 원작 스킬 정의로 대체하지 않았다.
- 일반 공격 생명력 흡수와 모든 피해 흡혈을 구분한다. 실제 HP 감소분만 회복 근거로 삼아 보호막·초과 피해를 제외한다. 광역 50%, 야생동물 60% 계수는 공통 함수에서 검사했지만, 기존 야생동물 전투 전체를 이 경로로 교체한 것은 아니다.
- 이름/전투 점수에서 나온 추가 방어 보정을 일반 피해 차감에서 제거했다. 전술 보호막이 피해 전부를 막은 경우 `0`이 원피해로 되돌아오던 오류도 수정했다.
- 피해 사건에 원피해·적용 방어·배율·치명타·실제 HP 감소·남은 HP를 기록하고, 전투 상세 로그에 기본 공격/스킬 구분과 계산 근거를 표시한다.

팀 검사 11/11과 캐릭터 스킬 검사 통과. 지원 검사에서는 공격력 60 / 방어 10의 피해 55가 HP 50인 동료에게 치명적이도록 명시하고, 실제 회복 지원이 있을 때만 생존하는 동일 기준을 유지했다. 스킬 검사에 있던 방어 무시 기대값은 방어 10을 적용한 독립 계산값(10→9, 21→19)으로 바꿨다. 단순히 실패 조건을 제거하지 않았다.

동일 최종 빌드의 로컬 `/eternalhunger`, 비로그인 기본 스쿼드·캐릭터 스킬 켜짐·x32로 진행했다. 시작 편성 1팀은 구름/솔빛/매화였다. 06:08 상태에서 19명 생존+5명 사망, 전투 상세 79개와 실제 피해 설명을 확인했다. 예: 가람→초롱 기본 공격 원피해 84.8/적용 방어 26.2/HP -67, 이어 전술 스킬 원피해 6/동일 방어/HP -5. 보호막 차감 및 무기 스킬·흡혈도 별도 로그로 표시됐다.

## 남은 범위

후속 변경(2026-09-05): 핵심 상태의 실제 경로 연결은 `combat-status-verification.md`, 기본 공격 간격·시간 정밀도는 `combat-timing-verification.md`에서 진행했다. 이 문서의 브라우저/재경기 수치는 당시 피해 구현 버전에만 해당한다.
