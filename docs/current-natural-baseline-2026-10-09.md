성장 진행 완료는 초기 목표 구성과 슬롯 수를 유지한 상태에서 제품의 진행 규칙으로 측정한다. 같은 슬롯의 상위 티어 대체를 허용하므로 지정 아이템 ID 자체의 제작·장착 증명과는 다르다. 별도 5슬롯 지표는 실제 인벤토리의 양수 수량, 장착 슬롯, 영웅 이상 티어와 무기 호환성을 확인한다. 최초 진행 완료는 발행 프레임 기준 21~56초였고 첫밤 종료 기한 250초보다 빨랐다.

## 후퇴 진단의 생애 경계 수정

기존 집계는 `A→B` 후퇴와 사망·부활 뒤의 `B→A` 후퇴를 같은 생애의 연속 왕복으로 세었다. 동일 지역 이동 알림도 실제 후퇴 수량에 들어갔으며, 객체 프로토타입과 같은 이름의 actor ID 집계도 누락됐다. 새 순수 회귀 검사 9항목 중 5항목이 수정 전 실패했고 원 실패 기록은 그대로 보존했다.

수정한 집계는 사망·부활·차원 전장 이동에서 해당 대원의 연속 이동을 끊고, 비영 이동 edge만 센다. 다른 대원의 사건은 연결을 끊지 않으며 일반 이동이 끼면 연속 팀 후퇴 쌍이 아니다. actor별 수량은 `Map`으로 독립 보관한다. 성장·거래·전투·행동 비용·난수와 승패 규칙은 바꾸지 않았다.

수정 후 신규 9항목, 기존 성장/합류/이동 측정 22항목, 상세 추적 14항목, 소스 지문 4항목이 모두 통과해 집중 명령은 종료 0이었다. 이 검사는 과거 결과 JSON이나 보고서를 입력으로 요구하지 않는다.

**위 6경기는 수정 전 집계 모듈을 이미 읽은 실행이므로, 그 후퇴 숫자는 수정된 집계기의 결과로 승계하지 않는다.** 다른 성장·합류·일반 이동·사냥·종료 관측과 원 명령의 종료 0은 해당 실행 범위로 보존한다.
