# 이터널 헝거 관전 평가표

## 작성 전 · JSON 파일 첨부 안내 (선택)

**가능하면 경기 JSON을 저장해 평가와 함께 첨부해 주시와요.** 문제 상황을 더 자세히 확인하는 데 도움이 된답니다.

- **경기 로그:** 경기를 마친 뒤, **새 경기 시작·새로고침 전에 경기 종료 화면의 ‘JSON 저장’**을 눌러 파일을 보관해 주시와요.
- **평가 답변:** 게임 안 설문을 작성했다면, 설문 아래 **‘결과 JSON 다운로드’**로 답변을 별도 파일로 저장할 수 있답니다. 이 파일은 경기 로그와는 다르답니다.
- 파일은 **자동 전송되지 않으니**, 테스트를 요청한 사람에게 평가와 함께 직접 보내 주시와요.

**파일이 없어도 평가할 수 있답니다.** 이 경우 기억나는 경기 시각·팀·캐릭터와 스크린샷만 첨부해도 도움이 된답니다.

한 경기를 평소 보고 싶은 속도로 관전한 뒤 작성하는 약 5분 평가표랍니다. 잘된 점과 불편한 점을 모두 적어 주시와요. 게임 규칙을 외우거나 내부 계산을 검증할 필요는 없답니다.

- 본 경기 수 / 실제 관전 시간:

- 이전 경험: 헝거게임 시뮬레이터 / 이터널 리턴 / 둘 다 / 둘 다 없음

## 2. 관전하면서 느낀 점

점수: **1 전혀 아니다 · 2 대체로 아니다 · 3 보통 · 4 대체로 그렇다 · 5 매우 그렇다**

그 장면이 없었거나 보지 못했으면 **‘관찰 못 함’**으로 표시하시와요. 장면을 보았지만 무슨 상황인지 알 수 없었다면 낮은 점수와 이유를 적는 것이 맞답니다. 모든 칸에 긴 설명을 쓸 필요는 없으며, 특히 좋거나 불편한 항목에 장면을 덧붙여 주시와요.

- 딱 하나 먼저 고친다면:

장면을 적을 때 **경기 시각(예: 2일 밤), 지역, 팀·캐릭터, 당시 배속** 중 기억나는 것만 함께 적어 주시와요. 스크린샷이나 경기·평가 JSON이 남아 있으면 첨부할 수 있지만, 없어도 평가할 수 있답니다.

**평가를 정리하는 사람용 메모**

- 점수와 감상은 실제 관전자만 작성. 자동 검사 결과로 빈칸을 채우지 않음.
- ‘관찰 못 함’과 미응답은 평균에서 제외하고, 응답 수를 함께 기록.
- 지도·팀 구분, 개인 탈락·팀 최종 탈락, 재미·즉시 재관전 의향을 합쳐서 하나의 점수로 판단하지 않음.
- 관전자가 말한 현상과 개발자가 추정한 원인을 구분. 낮은 점수만으로 특정 엔진 버그를 확정하지 않음.
- 보스 이어받기나 희귀 자원 경쟁처럼 드물게 나타나는 장면은 일부러 찾아보도록 요구하지 않음. 실제로 보았다면 자유 서술에 기록.
