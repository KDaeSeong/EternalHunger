# 키보토스 오토체스

공개 경로: /myanime/kivotos-autochess/play
직접 경로: /games/kivotos-autochess/play

## 구현 범위

플레이어 1명과 AI 7명의 로컬 대전이다. 학생 20명, 학원 4종, 역할 3종, 공용 기물 풀, 5칸 상점, 대기석 9칸, 레벨 3~8, 합성 1~3성, 정찰, 전투 다시보기, 최종 순위를 제공한다. 실시간 다인 대전은 포함하지 않는다.

골드 12와 체력 40으로 시작한다. 상점 리롤은 2골드, 경험치 4 구매는 4골드이며 라운드 종료마다 경험치 2를 얻는다. 기본 수입 5, 승리 1, 연승/연패 보너스 최대 3, 이자는 보유 골드 10당 1이다. 지능 2단계마다 이자 상한이 1 증가하고 지능 1단계마다 리롤 비용 환급 확률이 4% 증가한다. 행운은 현재 레벨에서 열려 있는 상위 등급으로 최대 10%p를 이동한다. 훈련은 각 5단계까지 가능하다.

등급별 기물 수량은 학생마다 24/20/16/12/10개다. 판매와 탈락 시 성급에 해당하는 기본 기물 수량(1/3/9)을 돌려준다. 상점의 미구매 기물도 예약 수량에 포함한다. 잠근 상점은 다음 라운드에도 유지한다. 같은 학생의 중복 출전은 시너지에 1명으로 계산한다.

## 전투와 재개

6열 8행 전장에서 0.2초 간격으로 이동, 공격, 표적 탐색과 스킬을 계산한다. 최장 60초이며 동률은 잔여 전력과 저장된 난수로 판정한다. 전투 시작 시 모든 대진의 결과를 한 번 계산해 저장한다. 화면 재생, 건너뛰기, 재접속은 결과를 새로 계산하지 않는다. 라운드 정산은 한 번만 적용한다.

학생의 기본 체력/공격력/등급과 스킬 수치는 이 게임용 밸런스다. 원작 게임 수치나 전투 규칙을 그대로 재현한다는 의미가 아니다.

마지막 전투만 최대 152프레임, 16명, 프레임당 효과 12개까지 보관한다. 로그 36개와 라운드 이력 12개를 유지한다. 저장 파일은 500KB를 넘으면 거부한다. 전투 중 저장은 같은 장면에서 일시정지로 복원한다. 오프라인 골드 보상은 없다.

## 저장과 기존 데이터 보호

손님/계정별 기기 저장 키는 eh:kivotos-autochess:v1:이며 다른 게임 키를 사용하지 않는다. 변경 시 5초마다 저장하고 페이지를 벗어날 때 저장한다. 새 대전과 가져오기는 직전 진행을 별도 복구본으로 남긴다. 손상되거나 지원하지 않는 원문을 자동으로 덮어쓰지 않는다. 다른 탭에서 동일 키가 변경되면 진행을 멈추고 내보내기와 복구를 안내한다.

계정 저장 슬롯은 kivotos-autochess-main이며 기존 공통 /game-saves API를 사용한다. 전적 등록은 최종 순위 확정 후 사용자 버튼으로만 수행한다. 자동 등록하지 않는다.

## 공식 일러스트

학생 21명의 기본 의상 얼굴 아이콘을 공통 경로 client/public/games/shared/blue-archive에 보관한다. 오토체스의 20명과 무한 디펜스의 6명이 공유하며 유즈만 디펜스 전용이다.

원본은 블루 아카이브의 공식 게임 일러스트를 보관한 커뮤니티 SchaleDB 저장소의 학생 아이콘이다. 해당 저장소를 공식 운영 사이트라고 표기하지 않는다. 한국어 이름과 게임 내 학생 ID를 대조한 뒤 기존 얼굴 크롭을 160×160 WebP로 변환했다. AI 생성 이미지나 팬아트를 사용하지 않았다. 원본 주소, 저장소 고정 리비전, 원본/결과 해시와 크기는 같은 폴더의 sources.json에 있다.

공식 사이트: https://bluearchive.nexon.com/
자료 저장소: https://github.com/SchaleDB/SchaleDB

## 검증

검사: node scripts/check-kivotos-autochess.mjs
27개 검사, 40개 시작 조건, 564라운드, 고스트 대진 118회가 통과했다. 최대 관측 저장 크기는 131,238바이트다. 공용 기물 보존, 합성, 대기석 포화, 위치 교환, 성장 한도, 레벨별 확률, 이동, 공격/회복/보호막/지휘 스킬, 중복 정산 방지, 전투 복원, 손상 데이터와 계정 분리, 최종 순위를 검증한다.

실제 브라우저/모바일, 배포 및 실제 계정 쓰기 검증 결과는 .local/kivotos-autochess/completion.json의 별도 항목을 따른다. 다른 게임에서 통과한 계정 검증을 이 게임의 검증으로 간주하지 않는다.
