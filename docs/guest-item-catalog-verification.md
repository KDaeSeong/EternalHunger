## 구현 범위

- 서버와 동일한 순수 정규화 함수를 사용해 브라우저용 아이템 카탈로그를 생성하고 버전·원본 해시를 고정.
- 게스트는 카탈로그 준비를 기다린 뒤 참가자·파밍 경로를 생성. 아이템이 없는 상태로 경기를 준비하지 않음.
- 레시피가 있는 카탈로그에서는 재료 없이 장비를 지급하는 초반·후반 보정 차단. 정상적인 시작 장비 지급은 유지.
- 제작 대상의 실제 등급과 무기 종류를 적용하고, 재료 소비 후의 가방 공간으로 제작 가능 여부 판단.
- 필드·루트 파밍에서 마지막 제작 재료를 받을 공간이 없으면 관련 없는 저등급 일반 재료 하나를 정리. 필요한 재료·특수 재료·장비는 보존.
- 결과 화면에 실제 레시피 제작 횟수 표시. 내보낸 경기 기록에 참가자와 팀 식별 정보 추가.

## 자동 검사

`client`에서 `npm run check:eternal-hunger` 전체 통과: 기존 회귀 검사, 카탈로그, 파밍·제작, 로컬 기록, 부활, 참가자 편성, 미니맵, 무기, 스킬, 피드백·음원, 런타임 린트 및 프로덕션 빌드. 수정한 서버 파일의 구문 검사도 통과했사와요.
