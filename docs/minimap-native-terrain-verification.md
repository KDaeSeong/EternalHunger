# 루미아 금지구역 지형 표시 수정

2026-11-15. 사용자 제보는 현재 금지 지역 목록의 차이가 아니라 빨간 경계와 배경 지형의 어긋남이다.

## 변경

기존 단순 다각형의 반투명 빨간 면과 외곽선을 원본 지도 위에 그리면 바다·그림자까지 덮고, 굴곡진 일부 지형을 빠뜨렸다. 기본 루미아 지도는 같은 원본 PNG의 파란 지형만 붉게 바꾼 이미지를 선택된 지역의 표시용 클립 안에 그린다. 지명 사각형과 원래 노란 키오스크·청록색 시설 표식은 보존한다. 이미지의 좌표 변환과 종횡비는 배경과 동일하다.

표시용 클립은 원래 지역 다각형의 엄격한 내부에 속한 원본 픽셀 중심 276,291개를 같은 지역으로 유지하고, 미포함·경계 중심 175,193개만 가장 가까운 기존 변에 배정한다. 겹침 없는 21개 영역으로 생성하며 문자열은 모듈 로드 때 한 번 계산한다. 이는 1px 중심의 표시 범위 계약이다. 공식 지리 경계·충돌·이동 가능 지형의 새 정답 데이터는 아니다. 원래 내부 경계를 다시 설계한 변경도 아니다.

옛 지역 ID `pond`·`residential`은 표시 도형만 `park`·`apartment`에 대응한다. 실제 등록 ID와 금지 집합의 소속은 그대로 비교한다. 사용자 지도는 자신의 도형과 기존 표시 방식을 사용한다. 원본 PNG·기존 지형 좌표·지역 재고·금지 시각·경기 계산은 변경하지 않았다.

## 검증

- `npm run check:lumia-minimap`: 생성 데이터 일치, 기존 지형·팀 표시·참조 지도·상호작용·화면 배치와 새 실제 컴포넌트 검사 14그룹·13그룹 통과.
- 변경 파일 ESLint와 비공개 픽셀 검사 도구의 문법 검사 통과.
- 동일하게 동결한 도구로 원형 `5b7728a0`와 수정본을 각각 한 번 실행했다. 빈 집합·전체·부분 8지역·현재/옛 ID 쌍·미등록 ID의 6장면을 원본 해상도 728×789와 CSS 화면 552×537, 390×700, 1280×720에서 확인했다. 수정본 24/24 통과다.
- 원본 해상도 전체 금지 장면의 574,392픽셀 중 지형 선택 242,730픽셀의 도색 오류 0, 나머지 보호 오류 0이다. 원본 PNG와 기존 도형으로 독립 선정한 21개 중심점은 선택 132·미선택 372표본 모두 통과했다. 대표 2장의 실제 페이지 PNG와 SVG 복제 렌더도 픽셀 오차 2 이하이며, 두 ID 쌍은 네 크기에서 같은 그림이다.
- 원형은 실제 파란 지형 7,806픽셀의 미도색과 바다 `[77,80,91] → [110,90,98]` 변색을 재현했다. 원형의 별도 DOM/복제 렌더 13픽셀 차이도 실패 그대로 보존했다. 앞선 검사 도구·환경·후보 실패를 덮어쓰지 않았다.
- 두 모드의 입력 7개 해시가 실행 전후 동일하며, 외부 요청·쓰기·경기·계정 저장 0회다. 소유 브라우저·컨텍스트·로컬 서버는 종료했다. 독립 감사의 추가 차단 지적은 없다.
- 같은 소스 1,631개의 실제 프로덕션 빌드와 필수 Worker 첫 단계 검사가 통과했다. 빌드 ID는 `PW72MzdDPwmB-_totrL4z`이며 입력 해시·엔진 지문은 빌드 전후 동일하다. 공개 전달은 정확한 커밋의 배포와 정적 자산을 별도로 대조한다.

원자료와 실패 원형은 `.local/code-audit/minimap-restricted-boundaries/`에 남긴다. 엔진 지문은 `d76d3e9900318ff0813094c7ab307451f9d3ca2b8a0c94a947697f23ec03bc62`로 유지한다.

## 인수 범위

원본 해상도 비교는 실제 컴포넌트의 바깥 SVG만 원본 이미지 프레임으로 정규화한 정적 검사다. 나머지 세 크기는 실제 CSS 컴포넌트 검사이며 전체 앱의 펼친 지도나 장시간 관전 성능을 뜻하지 않는다. 원래 G4 전경 배속·메모리, G5 고정 비교 실패 및 사람의 지도 이해도·재미 평가는 계속 남는다. 이 수정만으로 전체 목표를 완료 처리하지 않는다.
