## 중단 이후 소스 수정 — 당시 미실행 기록

검증 중단을 유지한 채 보조 편집 경로를 수정했다. 이 절 이후의 과거 통과 결과는 이 수정의 통과 증거가 아니다. 새 엔진 버전 생성, 테스트, 정적 검사, 빌드, 서버, 브라우저 경기는 실행하지 않았다.

- 코드 미리보기는 공통 정의의 허용 필드를 재사용한다. 별도 목록에서 빠지던 상태, 피해 종류, 공격력 계수, 이동 포함 정보를 유지하도록 수정했다. 잘못된 상태가 있으면 조용히 빈 상태 목록을 출력하지 않고 미리보기 생성 불가 이유를 표시한다.
- 상태가 명시된 스킬은 설명 변환으로 타입을 자동 변경하지 않는다. 변환 전 입력 오류나 변환 후 피해/상태 충돌은 `ok: false`로 반환하고 두 편집기 모두 기존 초안을 유지하도록 연결했다.
- 설명에 없는 지원 대상/HP 조건/사용 조건을 자동 초기화하지 않는다. 명시적 0%와 문장에 없는 조건을 구분한다.
- 공통 편집기에서 값을 수정할 때마다 이전 초안을 정규화하여 잘못된 상태 목록이 사라지는 경로를 제거했다. 저장 직전에도 원시 상태 입력 오류를 검사한다.
- 상태 전용 스킬과 계수만 있는 피해/재발동을 효과 없음으로 안내하지 않도록 수정했다.
- `check-character-skill-authoring.mjs`에 **16개 검사 항목을 작성만 했다**. 전체 허용 필드/21종 상태의 미리보기→편집 정규화→실제 정의 전달, 충돌 시 보존, 조건 유지, 명시적 0, 상태 없는 원문, 기존 증폭 회복 등을 다룬다. `check:skills`에 연결했지만 실행 결과는 아직 없다. 두 편집기의 실제 입력/저장 오류 화면 검사도 남아 있다.
- 후속으로 일반·궁극기·전술 쿨다운 감소와 고정 쿨다운을 편집/저장/실제 캐릭터·무기·전술 재사용 시각에 연결했다. 혼합 단위 장비 CDR을 정규화하고, 활성 가속/둔화 효과의 소수 만료 경계를 적분해 이미 진행 중인 절대 쿨다운도 갱신한다. `check-cooldown-semantics.mjs`의 13개 검사는 작성만 했으며 실제 저장/시간축 경기 확인은 남는다. `cooldown-semantics-verification.md` 참조.

## 구현한 경로

사용자 Q/W/E/R 정의 → 공통 편집기 → 기존 게스트 프로필 저장/복원 → 실제 AI 선택 → 시전/취소 → 피해 처리 후 상태 부여 → 관전 사건 → 저장 입력 재경기.

- 기존 `eh_guest_character_profiles_v1`와 `schemaVersion: 1`을 유지했다. 상태가 없는 기존 프로필도 읽으며 팀·HP·장비·쿨다운 등 실시간 상태는 저장 정의에 넣지 않는다.
- `statusEffects`에 상태명, 적용 대상, 지속 시간과 필요한 수면/감속 수치만 보존한다. 외부에서 주입한 태그·면역·시전자 ID·잔여 시간은 복사하지 않는다. 미지원 상태·잘못된 대상/수치·중복/과다 입력은 기존 저장을 덮어쓰지 않고 거부한다.
- 실제 처리된 21종만 선택할 수 있다: 기절, 속박, 침묵, 실명, 이동 속도 감소, 에어본, 공포, 매혹, 도발, 수면, 변이, 제압, 무적, 대상 지정 불가, 회피, 이동 방해 면역, 저지 불가, 모든 방해 면역, 해로운 효과 면역, 해로운 효과 제거, 경직.
- 피해 없는 상태 전용 공격을 지원한다. 새 `support_skill`은 아군 보호/정화용이며 공격 피해·계수를 넣으면 저장을 거부한다. 회복/보호막 수치는 함께 사용할 수 있다.
- 적에게 해로운 상태, 자신 또는 선택된 아군에게 보호/정화를 적용한다. 공격 광역은 실제 중심·반경 안의 적에게만 적용하고 자신 효과는 한 번만 적용한다.
- AI 예상은 상태/난수를 변경하지 않는다. 면역, 지속 시간 저항, 남은 효과와 정화할 해로운 상태 유무를 고려하며 확률 저항은 실제 적용 때 판정한다.
- 실제 스킬 피해/무기 후속 피해가 끝난 뒤 상태를 부여한다. 새 수면이 같은 공격으로 곧바로 깨지지 않으며, 사망한 대상에게 상태를 추가하지 않는다. 보호막에 흡수되거나 무적으로 피해가 막혀도 대상 지정 가능한 상태라면 CC 적용 여부를 별도로 판정한다.
- 기본 공격 강화의 상태는 준비 시점이 아닌 실제 기본 공격에 적용한다. 빗나간 강화 공격은 소모되지만 상태를 흘려보내지 않는다. 취소된 시전의 대상/자신 효과는 발동하지 않는다.
- 공포/매혹/도발에 실제 시전자 ID와 위치를 전달한다. 다른 스킬을 시전 중인 대상에게 CC가 적중하면 실제 시전 취소로 이어진다.
- 캐릭터 상태 사건에 시전자·스킬·대상·시전 ID·부여/면역/저항/정화·지속 시간 감소를 남기며, 관전 팀 양쪽에서 읽을 수 있다.

## 명시적 프로젝트 규칙과 제한

- 한 스킬에 최대 4개, 지속 시간 0.001~60초, 즉시 정화는 0초다. 배열 순서로 적용한다. 상태 지속 시간은 현재 스킬 레벨에 관계없이 입력한 고정 초다.
- AI는 같은 상태가 새 지속 시간의 절반보다 많이 남아 있으면 재부여 가치를 주지 않는다. 이는 프로젝트의 낭비 방지 정책이며 원작 AI 재현이 아니다.
- 수면 기본 추가 피해 20%, 변이 기본 감속 50%, 둔화 기본 감속 18%는 프로젝트 값이다. 수면 0~100%, 감속 0~75%를 직접 입력할 수 있다. 명시적 0은 보존한다.
- 지원 대상의 `자신+팀원`은 후보 범위이며 한 명을 선택한다. 아군 전체 동시 광역 지원을 의미하지 않는다.
- 설명에서 수치 채우기는 기존 피해/회복/보호막/패시브 입력 보조다. 자유 문장만으로 미구현 CC나 이동기를 만들지 않는다. 상태는 직접 선택한다.
- 기본 게스트 명단에 원작 스킬을 자동으로 창작·추가하지 않았다. 원작 전체 실험체·이동기·고유 자원 완성을 뜻하지 않는다.
