# 스킬 증폭 단위·가방 포화 성장 정체 수정

날짜: 2026-09-27
엔진: `95c60ec89fb71530f74eee80f4e22415d58f9a2e7e6b2601ad6f7981ffb3c29d`

## 범위와 재현

- 지인의 원 경기 JSON은 없음. 첨부 스크린샷은 문제 보고이며, 아래 통제 입력은 원 경기를 복원한 자료가 아님.
- 기존 일반 장비 `천국의 계단`의 `skillAmp: 68`을 전투 코드가 일괄 100배로 읽었음. 기본 증폭 12·고정 피해 10·현재 HP 148의 20%·증폭 계수 0.5인 통제 입력에서 원피해 3446이 산출되었음. 기본 증폭 12는 재현용 가정이지 원 캐릭터의 확인된 수치가 아님.
- 별도 성장 입력: 5일 차, HP 115, 625Cr, 가방 10칸, 무기·신발 장착. 첫 목표는 재료를 소비해도 묶음이 남아 결과물을 넣지 못하지만, 다른 목표는 두 재료 묶음을 소비해 빈 장비 칸을 채울 수 있음. 수정 전에는 첫 목표를 계속 선택했음.

## 변경 계약

- 일반·커스텀 장비의 스킬 증폭은 가산 능력치 그대로 읽음. 소수 0.5도 0.5이며 값의 크기로 단위를 추측하지 않음.
- 과거 자동 생성 장비는 기존 예약 식별자 `wpn_`/`eq_`로 구분하여 0.5 → 50 해석을 유지. DB에 보관된 경우 `itemKey`/`externalId`도 확인. 저장 원본을 일괄 변환하거나 덮어쓰지 않음.
- 구형 전투 점수 계산의 합산 API는 기존 단위를 유지하되, 개별 장비를 변환한 후 합산. 실제 피해는 해당 점수 API의 상한을 사용하지 않음.
- 가방이 꽉 찬 성장 계획은 재료·비용뿐 아니라 실제 제작 거래의 결과물 수령 가능 여부를 확인. 현재 목표 안의 다른 부품 또는 다른 설정 목표로 재계획.
- 보호 재료 강제 폐기, 무료 장비 지급, 제작비 면제, 가방 상한 확대 없음. 막힌 경우 관전 설명은 가방 공간 부족으로 표시.
