# 지역 내부 거리·사거리·시야 연결

기준일: 2026-09-05. G2.3의 실제 전투 공간 판정 단계다. 전체 목표 완료나 원작 지형·실시간 액션 전체 재현을 의미하지 않는다.

후속 기록: 면역·지속 시간 저항, 상태 만료 경계와 보호 종료 후 이동 재개 보강은 `status-protection-verification.md`에서 진행한다. 아래 전체 회귀/브라우저 수치는 공간 단계 엔진의 증거이며 후속 엔진의 최종 통과로 재사용하지 않는다.

## 구현 범위

- 각 지역에 프로젝트 규칙인 24m 정사각형 좌표를 둔다. 최초 위치는 참가자 ID와 지역으로 결정하며 경기 난수를 소비하지 않는다. 기존 좌표는 복제·보존하고 지역 변경/부활/새 경기의 이전 이동 예약은 정리한다.
- 기본 이동 속도는 프로젝트 기본값 3.5m/s다. 명시 능력치·패시브·장착 장비·특성·영구 보너스·활성 상태를 반영한다. 이동 불가와 둔화의 소수점 만료 경계도 나누어 적분한다.
- 실제 시간축에서 기본 공격 접근과 지역 내부 탐색을 진행한다. 전투 이동 판단 간격은 0.25초이며, 피해·성장·상태와 같은 경기 시계를 사용한다. 모든 참가자의 이동을 같은 시작 상태에서 계산한 뒤 반영한다.
- 적 발견은 본인 또는 살아 있는 팀원의 시야를 사용한다. 시야 밖의 적 위치를 목적지로 가져오지 않는다. 놓친 적은 마지막 목격 위치만 최대 3초 탐색하며, 그 뒤 일반 지역 탐색으로 돌아간다. 지역 탐색은 보이지 않는 적 좌표에 의존하지 않는다.
- 실제 기본 공격 실행 전에 사거리·시야를 검사한다. 불가능한 공격은 피해·전술 부가 피해·공격 재사용 시간을 소비하지 않는다. 사거리 밖이면 접근하고, 안에서는 개인 공격 간격을 유지한다.
- 스킬 AI의 표적 선택·아군 지원·광역 밀집 판단을 실제 거리로 계산한다. 일반 스킬은 시전 중 시야/사거리 이탈로 취소된다. 기본 공격 강화는 자신에게 준비하고 다음 실제 기본 공격의 유효 표적에 사용한다.
- 광역은 실제 주 대상의 위치를 중심으로 반경을 계산한다. 같은 지역이라는 이유만으로 모든 적을 맞히지 않으며, 적용 직전에도 저장된 중심과 표적 거리를 확인한다. 일반 표적 공격과 별개로 광역 반경 안의 대상마다 시야를 요구하지는 않는다.
- 팀 집중 공격은 공격 가능한 표적 중에서 선택한다. 후퇴 엄호도 추격자에게 실제로 닿는 팀원만 참여하고 행동 비용을 사용한다.
- 직접 피해 기록에는 거리·허용 사거리·시전자/표적 좌표, 광역 기록에는 중심·반경·중심으로부터의 거리를 남긴다.
- 관전창에 지역 내 좌표·평타 사거리·시야·이동 속도·이동 계획과 거리/시야 취소 이유를 연결한다. 미니맵 생존/사망 표식은 지역 내부 좌표를 축약 표시한다. 원작 지형 축척이 아니라는 안내를 추가했다.

## 통제 검사

`node scripts/check-combat-spatial.mjs`: **24/24 통과**.

검사 항목은 실제 거리 및 경계, 다른 지역, 잘못된 좌표, 초기화/복제/부활, 팀 시야, 실제 피해 전 차단, 장착 보너스, 접근과 정지 거리, 속박·둔화 만료, 시간 분할·명단 순서 독립성, 마지막 목격지/탐색, 실제 실행기의 접근 후 공격·원거리 시전·거리/시야 취소·광역·집중 공격·엄호, 강제 교전 없이 탐색 후 적 발견, 관전 문구의 순수성을 포함한다.

관측 예: 7m 떨어져 있고 상대는 속박된 조건에서 3.5m/s로 접근한 공격자는 1.75초 후 첫 평타를 낸다. 1.5m 사거리 이내 피해만 발생한다. 이는 0.25초 판단 간격의 프로젝트 실행 결과이며, 연속 충돌 시점의 해석해를 주장하지 않는다.

후속 실패 재현과 수정: 사거리 안에 도달해 이동 예약을 지우면 마지막 목격 위치까지 잊는 결함을 통제 검사로 재현했다(`patrol`이 아닌 `last_seen`이어야 함). 목격 기억을 `_spatialLastSeen`으로 분리해, 공격 중 정지하거나 시전하더라도 실제로 관측한 위치를 기억하도록 수정했다. 새 경기/부활/지역 변경에서는 이전 기억을 정리한다. 추가 검사와 28개 독립 시전 검사 통과 후, 아래 최신 엔진의 전체 검사도 정상 종료했다.

기존 피해 19/19, 상태 23/23, 시간 26/26, 독립 시전 28/28, 팀 교전 11/11도 명시적으로 접촉 좌표를 제공하는 통제 조건에서 통과했다. 좌표가 없으면 접촉한 것으로 간주하는 실행기 우회는 추가하지 않았다. 스킬 컴파일러/실행 검사와 런타임 정적 검사도 통과했다.
