# 문명 아카이브 생산·교육 재료 안내

## 사용 범위

기존 부족 화면의 가공 계획과 공교육 계획에 접이식 공급 안내를 연결한다. 입력 중인 초안이 아닌 **저장된 계획**을 기준으로 하며, 안내를 여는 것은 생산·지역 지정·연구 목표 변경을 실행하지 않는다.

| 상황 | 안내하는 내용 |
| --- | --- |
| 가공 재료 부족 | 실제 레시피 1묶음의 보유·필요·부족 수량과 확인된 획득 경로 |
| 가공품이 재료인 경우 | 실제 지원 공정의 1묶음 산출과 바로 아래 투입 재료 |
| 공교육의 종이 공급 | 실제 제지 공정의 공급 경로·투입 재료·선행 연구 |
| 연구 미완료 | 실제 공정·전문 행동이 요구하는 기술의 발전 화면 안내 |

지도에서 확인을 누르면 발견한 실제 지역과 해당 획득 행동을 안내한다. 선행 연구 보기는 발전 화면의 해당 연구를 설명한다. 실제 지역·행동·연구·계획 선택은 기존 화면에서 사용자가 직접 수행한다. 안내는 획득 성공이나 다음 아침 산출을 보장하지 않는다.

## 데이터와 불변 조건

- 가공 7종의 재료·산출·해금은 엔진의 실제 레시피와 행동 정의에서 구조화해 전달한다. 화면 문자열을 역으로 해석하거나 안내용 수치를 따로 복제하지 않는다.
- 가공의 수량은 전체 목표 비축에 필요한 총량이 아닌 **1묶음 기준**이다. 공교육은 종이 공급 방법만 설명하며 `supplyOnly`와 필요량 미지정을 사용한다. 교원 수로 새로운 수요·비축 목표를 만들지 않는다.
- 재고 관찰은 유효한 소수를 보존하고, 없는 키만 0으로 취급한다. 명시된 null·문자열·불리언·비유한 값·음수·안전 범위 초과는 확인 불가로 표시한다. 기존 생산 계산이나 저장을 이 안내로 고치지 않는다.
- 직접 획득처는 실제 발견된 비안전 지역의 정규 식별자·지형과 실제 채집·사냥·전문 행동 정의를 대조한다. 가짜 지역·지형·수확 배열을 안내 근거로 쓰지 않는다. 지형 제한 없는 실제 생산 행동은 존재하지 않는 지도 지점을 만들지 않는다.
- 가공품은 지원되는 실제 공정 한 단계와 그 투입 재료의 현장 경로까지만 설명한다. 종이·주괴를 직접 채집한다고 표시하거나 재귀 생산 그래프를 무제한 전개하지 않는다.
- 지도 제작 전 채집·사냥의 무작위 지역 규칙과 전문 행동의 실제 지역 선택 규칙을 구분한다. 전문 행동을 무작위라고 잘못 안내하지 않는다.

## 클릭과 화면 보호

현재 런·상태 객체·행동 대원·저장된 계획을 확인하고, 요청한 범위·재료·지역·획득 종류·행동 또는 기술이 현재 안내에 실제 존재할 때만 이동한다. 중첩 가공품 투입 재료도 같은 검증을 거친다. 지도 화면은 현재 실제 안내에서 공급처를 다시 확인하며 채광 등 전문 행동과 필요한 연구를 표시한다.

안내의 계산과 클릭은 새 전체 상태 정상화나 난수 소비를 추가하지 않는다. 기존 캠프 안내, 입력 초안, 저장·쓰기 권한·상점 보호와 시대별 스타일은 유지한다. AP·재고·시간·공로·실제 선택값과 저장 상태를 변경하지 않는다.

## 검증 범위

새 집중 계산 검사 8그룹과 UI 검사 6그룹은 실제 엔진 요약·정규 데이터·컴포넌트·페이지 콜백을 사용한다. 실제 7종 레시피 대조, 잘못된 수량·공개 지역·한 단계 생산·교육 공급·불변성·난수, 오래된 콜백·위조 요청, 실제 전문 행동의 지도 표시와 기존 캠프 동작을 확인한다.

첫 RED는 제품 수정 전 실제 도구 관측이다. 저장된 `production-guide-followup-red.log`는 편집 시작 신호 뒤의 후속 실패 원문이며, 당시 소스 해시가 없어 최초 실행과 동일한 소스라고 소급 단정하지 않는다. 로그는 복사 없이 이름만 바로잡았으며 481바이트·SHA-256 `b9e8eff893f3aff06484882f8d73f1a0666338f00dedd1a024193dd89ce0a6ef`를 보존한다.

집중 통합에서는 위조 지역 허용과 안내 클릭의 불필요한 날씨 난수 소비를 발견해 수정했다. 지도 화면까지 전문 행동의 실제 공급처가 연결되는지와 지도 제작 전 설명도 확인했다. 기존 검사 하네스는 새 실제 import와 Fragment 내부 폼·콜백 바인딩을 등록하되 원래 가드·초안·비용·난수 단언을 유지한다.

첫 전체 검사 실행은 새 JSX 자식을 등록하지 않은 기존 하네스에서 중단됐으며 `.local/code-audit/archive-production-guide-checks-result.json`·동명 로그에 실패를 그대로 보존한다. 집중 검사와 이후 전체 검사·빌드·공개 전달은 각각 별도 증거로 구분한다. 실제 브라우저·키보드·사람의 이해도나 원래 전체 게임 목표의 완료는 자동 검사로 증명하지 않는다.

이후 실제 새 자식을 등록한 기존 발전·집중 화면·노동 방침·가공 전승 검사도 각각 종료 0이다. 최종 전체 `check:primitive-archive`, 공통 피드백 검사, viewport 검사와 변경 파일 린트는 모두 실제 종료 0이며 선언 소스 1,262개가 유지됐다. 근거는 `.local/code-audit/archive-production-guide-final-checks-result.json`이다. 첫 실패 기록을 성공으로 덮거나 과거 결과 파일을 검사 입력으로 사용하지 않았다.

배포용 빌드도 종료 0이며 ID는 `9A35qf8YUn2-mU5jD8mxH`다. 선언 소스 1,262개와 이터널 헝거 엔진 `e8e8b934…`는 유지됐다. 모듈 검사 23조건과 격리 Node VM Worker의 새 경기 첫 단계 완료 1회를 확인했다. `archive-production-guide-final-build-result.json`은 해당 빌드 증거이며, 브라우저의 지도 이동·실제 키보드·사람 이해도나 EH 엄격 관전 성능의 합격 증거가 아니다.
