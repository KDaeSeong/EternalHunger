# 무한 디펜스

첫 구현 범위는 고정 경로 맵 1개, 방어 거점 8곳, 학생 6명, 일반 적 4종, 20웨이브 보스와 이후 무한 모드다. 기본 경로는 /myanime/infinite-defense/play이며 /games/infinite-defense/play에서도 열린다.

학생은 방어·채굴·대기 중 하나만 맡는다. 방어 첫 배치에만 크레딧을 사용하며 재배치 시 추가 비용이나 환급은 없다. 손재주는 채굴 생산량, 사격 훈련은 사거리, 민첩성 훈련은 실제 공격 간격에 반영된다. 화력과 채굴 설비는 별도 투자다. 기본 생산은 초당 0.6이며 채굴 담당 학생의 생산량이 추가된다.

전투는 0.1초 고정 단계로 계산한다. 일반·돌격·장갑·군집의 네 종류와 매 20웨이브의 보스가 등장한다. 20웨이브 보스 격파 시 무한 모드가 열리며 보스가 출구에 도달하면 거점이 함락된다. 재정비 중 거점 수리에 55크레딧을 사용해 내구도를 5 회복할 수 있다. 자동 웨이브는 성공 후 4초 뒤 시작하며 20웨이브 완수 화면에서는 직접 무한 모드 진입을 선택한다.

기기 저장은 손님/계정 ID별 독립 키를 사용하며 5초마다 현재 작전만 보관한다. 새 작전·가져오기·계정 불러오기 전에 현재 작전을 직전 복구본으로 남긴다. 읽을 수 없는 기존 원문은 별도 unreadable 키에 보존한다. 형식이 다른 저장은 초기화하지 않고 거절한다. 다른 탭의 같은 저장 변경을 감지하면 자동 저장과 진행을 중단해 덮어쓰기를 피한다.

화면을 벗어나면 전투가 일시정지되며 복귀 시 최대 8시간의 채굴 수익만 정산한다. 적의 이동·피해·클리어는 오프라인으로 계산하지 않는다. 진행 중 전투를 불러오면 일시정지 상태로 복원한다. 로그인/로그아웃 시 저장 계정을 분리하고, 늦게 도착한 다른 계정의 서버 응답은 적용하지 않는다.

계정 저장과 전적은 기존 /game-saves 및 /game-records API를 사용한다. 사이트 LP·크레딧 보상은 이 첫 구현에 포함하지 않는다. 계정 전적은 20웨이브 완수 또는 패배 후 기록할 수 있다. JSON 내보내기와 1MiB 이하 가져오기를 지원한다.

검사는 client 폴더에서 npm run check:infinite-defense로 수행한다. 실제 획득 자원과 정식 행동만 이용해 20웨이브·보스 완수, 무한 모드 진입, 패배, 중간 전투 복원, 오프라인 정산 한도, 계정별 저장 격리와 손상 원문 보존을 검증한다. 브라우저/공개 배포 결과는 .local/infinite-defense의 완료 기록에서 따로 확인한다.
