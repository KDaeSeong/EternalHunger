# 다른 부위 자동 장비 제작의 목표 제작비 보존

2026-11-15. 현재 목표의 남은 제작비는 20Cr인데, 다른 부위 장비를 7Cr에
자동 제작하여 20→13Cr로 줄어드는 실제 거래를 재현했다. 원재료 예약과
소모품의 제작비 보호는 있었지만 다른 부위 장비에는 비용 보호가 빠져 있었다.

성장 계획과 무관한 장비는 남은 목표 제작비를 제외한 크레딧으로만 제작한다.
가방 제작과 획득 직후 제작은 같은 판정 함수를 사용한다. 목표 자체의 제작과
중간 재료, 자동 목표의 같은 부위 상위 대체, 직접 지정한 다음 목표의 기존
교체 규칙은 유지한다. 무료 제작과 실제 여유금으로 내는 비용도 허용한다.

다섯 부위의 순환 쌍을 두 제작 경로로 검증했다. 20/25Cr에서는 다른 부위의
7Cr 지출을 막고 실제 목표의 20Cr 지불은 허용한다. 27Cr의 정확한 여유금,
무료 업그레이드와 8+12Cr의 다단계 목표도 확인했다. 예약 검사는 84/84이며,
연속 획득 제작의 검사 입력은 제품의 getLootCraftOptions를 사용하여 실제
revision·행동 주기·카탈로그 정보를 보존한다.

관련 성장·거래·회복·후반 목표와 정적 검사 16명령은 같은 소스에서 종료 0이었다.
기존의 유료 첫 아침 통제 입력에는 별도 신발의 7Cr 제작도 추가했다. 일반 24인
경기 실행에서 지정한 세 대원이 각각 20Cr를 지불해 머리 장비를 착용했고,
그 전에 경쟁 소모품이나 신발을 제작하지 않았다. 첫 아침 140초의 5,056사건과
프레임 지문은 동일 입력의 noisy 재경기와 일치했으며 API 호출은 0이었다.

이 통제 입력은 20Cr와 섬유 4개, 유한한 염료 재고를 명시적으로 설정한다.
자연 무보정 분포·전체 경기·모든 커스텀·사람 평가의 합격으로 확대하지 않는다.
엔진 지문은 `8a703669…`에서 `e4fbfc91…`로 바뀐다. 기존 실패 편성 8회는
재실행하지 않았으며 전체 G1~G5와 실제 전경·자연 만료·사람 관문은 남는다.

전체 프로덕션 빌드 `jwjDjtzWDcGCLTPvbjXST`도 소스 1,617개와 새 엔진 지문을
유지하고 Node VM Worker 첫 단계까지 통과했다. 공개판의 실제 원본 경기와
보관함 동일 재경기는 푸시 후 별도 확인한다.
