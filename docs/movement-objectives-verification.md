- 현재 목표 카드는 같은 화면 프레임의 생존자·월드·금지구역을 읽는다. 일부 자원만 남았으면 남은 자원만 표시한다. 다른 팀 수는 같은 실제 대상을 노리는 살아 있는 필드 팀을 중복 없이 센다. 단순히 같은 지역에 있는 팀은 세지 않는다.
