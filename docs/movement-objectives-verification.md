# HF2 실제 자원 목표 표시

기준일: 2026-09-20. 사람이 전달한 요청은 팀이 생명의 나무·미스릴 같은 자원을 노릴 때 그 대상과 목적지를 알 수 있게 하라는 것이다. 관전 문구로 새로운 AI 판단이나 획득 성공을 만들어 내지 않는다.

## 구현 계약

- 개인/팀 이동 계획에서 최종 목적지를 고른 뒤 그곳의 실제 오브젝트 ID를 기록한다. 중간 경유지, 다른 후보 지역의 자원, 나중에 같은 지역에 생긴 새 자원을 그 결정의 대상으로 바꾸지 않는다.
- 자연 자원은 선택된 구역의 운석/생명의 나무를 구분한다. 보스의 재료 안내는 현재 경기의 드롭 규칙과 카탈로그에 존재하는 항목만 사용하며 확정 획득으로 표현하지 않는다. 전설/초월 상자와 차원의 틈도 실제 대상에 연결한다.
- 현재 목표 카드는 같은 화면 프레임의 생존자·월드·금지구역을 읽는다. 일부 자원만 남았으면 남은 자원만 표시한다. 다른 팀 수는 같은 실제 대상을 노리는 살아 있는 필드 팀을 중복 없이 센다. 단순히 같은 지역에 있는 팀은 세지 않는다.
- 자원 소진, 상자 개봉, 보스 사망, 금지구역, 틈 참가 마감/포기, 후퇴/회복/합류/최종 안전구역 우선 전환 시 오래된 자원 목표를 현재 카드에서 제거한다. 과거 사건은 시각과 함께 보존한다.
- 개인 목표의 유지 시간 동안 새로 제안된 다른 목적지의 이유·오브젝트 종류를 빌려 표시하던 결함을 수정했다. 소진된 목표를 유지 시간이 끝날 때까지 쫓는 경로도 재계획한다. 이 둘은 표시 외 실제 목표 기억 처리 수정이며, 전투 수치/보상 확률 변경은 없다.
- 팀 관전 카드의 펼침 밖에 목표/목적지/목표 공유 인원을 표시하고 목표 지정·변경을 경기 사건과 로그에 남긴다. 관전은 난수를 소비하거나 월드/가방을 수정하지 않는다.

## 남은 경계

이 카드는 실제 필드 오브젝트를 노리는 결정에 대한 표시다. 키오스크의 포괄적인 재료 구매 의도는 아직 구체적인 최종 구매 품목 확정과 연결되지 않으므로 이 카드에 임의의 재료를 추가하지 않는다. 일반 성장/합류/후퇴는 기존 관전 영역에 남는다. 다음 확인은 성장/팀 공동/키오스크 판단에서 실제로 선택된 목표의 전달 경로와, 실전의 구체적인 목표 활성·변경·소멸 화면 표본이다. HF2는 부분 구현 상태이며 HF3 수치 근거, HF4 합류 지연, HF5 교전 HP/팀 전멸, HF6 커스텀 아이템, HF7 사람의 재평가도 별도 미완료다. 전체 목표는 완료 처리하지 않는다.
