## 검증한 문제

팀 열세 후퇴가 두 지역 사이를 곧바로 왕복하는 문제와, 그 문제를 세는 진단기가 중간의 실제 이동을 무시하는 문제를 함께 확인했다.

- 후퇴 직전 지역 기억은 다음 모든 판단에서 무조건 사라지고 있었다. 제자리 합류 대기나 파밍 판단이 끼면 다음 실제 후퇴가 직전 위험 지역으로 되돌아갈 수 있었다.
- 기존 분포 진단은 두 `team_decision` 사이의 실제 이동을 보지 않았다. 제3지역을 거친 뒤 나중에 되돌아온 경우도 즉시 왕복으로 과대계수했다.
- 종료 구역 로테이션이 열세 판단보다 우선했는데도 `team_outnumbered` 관전 사건을 함께 발행할 수 있었다.

수정 뒤 후퇴 기억은 직전 지역 복귀를 실제로 보류했을 때, 도주·회복 탐색이 제외 지역을 사용했을 때, 또는 다른 지역으로 실제 이동했을 때만 소비한다. 분포 진단은 실제 이동 사유가 `flee:team_outnumbered` 또는 `flee:team_power_gap`인 이동만 팀 열세 후퇴로 세고, 서로 연속한 두 실제 후퇴 이동이 정확히 역방향일 때만 즉시 왕복으로 센다. 일반 `avoid_power`와 `endgame_rotate`는 별도 이동 사유로 남긴다.


각 시드는 다음을 모두 만족해야 통과로 판정했다.

- 종료 코드 0, 참가자 24명, 1~24페이즈 안에서 명시적 경기 종료
- `last_team` 또는 `no_survivors` 결과와 0보다 큰 종료 시각
- 실제 제작과 교전 존재
- 사냥 시작/종료/정산 ID 무결성 통과 및 미완료 사냥 0
