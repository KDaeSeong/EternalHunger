# 실험체 쿨다운 감소 의미 연결

기준일: 2026-09-06. 사용자가 제공한 실험체 능력치 중 쿨다운 감소·궁극기 쿨다운 감소·전술 스킬 쿨다운 감소를 G2.3 전투 시간축에 연결한 소스 계약이다.

## 구현 규칙

- `cooldownReduction`: Q/W/E/R과 무기 스킬의 기본 쿨다운에 적용한다.
- `ultimateCooldownReduction`: R에만 적용하며, 일반 쿨다운 감소와 서로 곱해 남은 시간을 계산한다.
- `tacticalCooldownReduction`: 전술 스킬에만 적용하며 일반/궁극기 쿨다운 감소와 섞지 않는다.
- `cooldownFixed: true`: 일반·궁극기 쿨다운 감소를 받지 않는다. 블링크는 기존 설명에 맞춰 고정 전술 쿨다운으로 표시했다.
- 모든 감소율은 `0.1 = 10%`이며 음수는 0, 과도한 합계는 95%에서 제한한다. 이는 0초 반복 사용을 막기 위한 이 프로젝트의 안전 경계이지 원작의 현재 상한을 주장하는 수치가 아니다.
- 캐릭터 스킬은 최소 0.25초, 무기/전술 스킬은 최소 1초를 남긴다. 경기 설정의 캐릭터 스킬 쿨다운 배율은 감소율과 별도로 적용한다.
- 이미 시작된 쿨다운은 활성 효과의 `쿨다운 감소 속도 증가/둔화`를 실제 남은 시간에 반영한다. 효과가 소수 초에서 끝나면 그 경계 전후를 나눠 적분하고, 캐릭터·무기·전술의 절대 사용 가능 시각을 같은 경기 시계에서 앞당기거나 늦춘다. 재발동 가능 시간은 쿨다운이 아니므로 바꾸지 않는다.

## 데이터와 실제 사용 경로

- `client/src/utils/erStats.js`: 세 능력치의 기본값·표시·정규화
- `client/src/app/characters/_components/CharacterSkillConfigFields.js`: 패시브 능력치 입력 및 개별 스킬의 `쿨다운 고정` 선택
- `client/src/utils/characterSkillCompilerCore.js`, 캐릭터 편집 정규화, 서버 비교/스키마: 고정 여부와 세 능력치의 저장 왕복
- `client/src/app/simulation/_lib/cooldownRuntime.js`: 기본/패시브/상태 능력치와 실제 장비 CDR을 합쳐 용도별 쿨다운 계산
- 캐릭터 독립 시전과 기본 공격 연계 스킬, 무기 스킬, 전술 공격·방어·도주·추격이 위 계산을 사용

장비 카탈로그에는 `cdr: 0.1`과 `cdr: 10`처럼 비율/백분율 자료가 함께 존재한다. 기존 합산은 `10`을 10%가 아니라 상한 75%로 만들 수 있었으므로, 다른 비율 장비 능력치와 같은 정규화 함수를 사용하도록 수정했다.

## 작성한 검사 — 미실행

`client/scripts/check-cooldown-semantics.mjs`에 다음 13개 검사를 작성했다.

1. 세 능력치 기본값과 0~100% 정규화
2. Q/W/E 일반 쿨다운 감소
3. R의 일반·궁극기 감소 곱연산과 비궁극기 격리
4. 고정 캐릭터 쿨다운의 감소 무시
5. 장비 `cdr: 10`의 10% 해석과 무기 스킬 연결
6. 패시브 능력치의 동일 유효 능력치 경로
7. 전술 전용 감소와 블링크 고정 예외
8. 편집/컴파일 데이터의 `cooldownFixed` 보존
9. 소수 초에서 끝나는 쿨다운 가속 효과의 구간 적분
10. 쿨다운 회복 둔화가 시간을 역전시키지 않고 실제 진행량을 줄이는지 확인
11. 현재 효과의 만료를 고려한 정확한 다음 사용 가능 시각 예측
12. 캐릭터·무기·전술 절대 시각 동시 갱신과 재발동 시간 불변
13. 아무 효과가 없을 때 절대 사용 가능 시각 불변

사용자의 `검증 중단` 지시에 따라 위 검사는 실행하지 않았다. 린트·빌드·서버·브라우저·경기도 실행하지 않았으며, 과거 검사 결과를 이 수정의 통과 증거로 사용하지 않는다.

## 남은 완료 증거와 잔여 범위

- 편집기 저장→새로고침→새 경기에서 세 수치와 고정 체크의 실제 복원
- 동일 시드에서 0%/일반/궁극기/전술/고정 조건의 실제 사용 시각 및 재경기 일치
- 장비 장착 전후 Q/W/E/R·무기 스킬 재사용 시각과 장비 교체 경계
- `쿨다운 감소 속도 증가/둔화`가 시전 선택·전술/무기 발동까지 이어지는 실제 소수 시간축과 재경기 일치 확인
- 궁극기 슬롯이 아닌 사용자 정의 스킬, 블링크 외 고정 쿨다운 자료의 명시적 입력과 관전 표시
- 원작의 현재 상한·합연산 방식·각 스킬의 쿨다운 고정 여부는 별도 출처 확인 전까지 이 프로젝트 규칙과 구분

따라서 쿨다운 능력치와 동적 회복 속도 경로는 소스에 연결됐지만 실행 검증은 미완료다.
