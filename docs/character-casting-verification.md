# 독립 캐릭터 스킬 시전 구현과 검증

기준일: 2026-09-05. G2.3 중 캐릭터 스킬을 기본 공격과 분리하는 단계다. 원작 전체 실험체 데이터·최신 수치·액션 전투 재현이나 재미·밸런스 합격을 뜻하지 않는다.

후속 기록: 로그인 없는 게스트의 실제 이름·Q/W/E/R·패시브·전술 편집/저장 경로는 `guest-character-profile-verification.md` 단계에서 연결했다. 기본 게스트에게 공식 스킬을 자동 제공한 것은 아니다. 아래 5,946개 사건 등은 독립 시전 단계의 통제 입력에 대한 역사적 증거로 보존한다.

공간 후속 기록: 같은 지역의 추상 거리 대신 실제 좌표·사거리·팀 시야로 시전 선택·취소·광역 판정을 연결했다. 최신 범위와 검증은 `combat-spatial-verification.md`를 따른다. 아래 당시 잔여 목록은 현재 완료 여부를 덮어쓰지 않는다.

## 변경 이유

종전 제품 경로에서는 기본 공격이 발생할 때 Q/W/E/R을 함께 평가하고 효과를 즉시 적용했다. 시전 시간과 후딜은 그 뒤의 행동 잠금으로만 반영됐다. 따라서 화면에 시전 시간을 넣더라도 실제로는 이미 피해·회복을 준 뒤였고, 다음 기본 공격까지 돌아온 스킬도 기다려야 했다.

이제 진행 중인 교전에서 다음 기본 공격, 스킬 선택·시전 시작, 시전 완료, 강화 기본 공격 대기 만료를 같은 경기 시계의 별도 사건으로 예약한다. 교전 발견 자체는 무료 선제 공격을 주지 않는다.

## 구현된 프로젝트 규칙

- 일반 캐릭터 스킬: AI 선택 → 대상과 스킬 정의/레벨 저장 → 시전 → 발동 → 후딜. 기본 공격이 없어도 쿨다운과 행동 제한이 풀리면 선택할 수 있다. 여러 스킬을 한 기본 공격에 몰아 붙이지 않는다.
- 피해·회복·보호막은 발동 시점에 실제 공통 적용 경로로 전달한다. 일반 스킬은 기본 공격 타이머를 소비하거나 무료 무기 후속 공격을 만들지 않는다. 피해 계산은 발동 시점의 공격자/대상 능력치와 보호 효과를 사용한다.
- 기본 공격 강화: 시전 완료 시 강화만 준비하고 다음 실제 기본 공격에 한 번 적용한다. 기본 공격의 표적이 바뀌어도 사용할 수 있다. 실명/회피로 빗나간 공격은 강화를 소비하되 피해가 새지 않는다.
- 강화의 대기 시간은 정의값 또는 기본 5초, 최소 1초다. 이는 이 프로젝트의 명시적 정책이지 원작 모든 강화 스킬의 공통 규칙이 아니다. 재사용 단계가 정의된 강화는 첫 타격 후 재사용 창을 열고 두 번째 시전도 별도로 거친다.
- 첫 시전 시작에 슬롯 쿨다운을 예약한다. 취소해도 환불하지 않고, 두 번째 시전은 첫 쿨다운을 유지한다. 현 단계는 기존 전역 쿨다운 배율만 적용한다.
- 사망, 시전자/잠근 대상의 지역 이탈, 대상 지정 불가, 팀 변경, 스킬 비활성화, 사용을 막는 상태가 시전을 취소한다. 대상이 사라졌다고 다른 대상으로 몰래 바꾸지 않는다. 자기 강화는 상대 이탈만으로 취소하지 않는다.
- 기절/침묵은 시전을 취소한다. 속박은 `includesMovement`로 표시한 이동 포함 스킬만 취소하며, 고정 위치 스킬은 유지한다. 무적은 대상 지정 불가와 달라 시전은 끝나되 실제 피해가 0이 된다.
- 상태/사망/이동을 관측한 세계 진행 및 각 전투 행동 경계에서 취소를 확인한다. 취소는 자신이 예약한 행동 잠금만 해제하고, 나중에 생긴 더 긴 잠금은 지우지 않는다.
- 발동하지 않은 시전과 강화는 참가자 상태에 남아 페이즈/JSON 저장을 넘어 이어진다. 부활은 이전 생명의 시전/강화를 지운다. 참가자별 시전 일련번호는 유지하여 사건 ID를 중복시키지 않는다.
- 시전 중에는 일반 파밍을 동시에 하지 않는다. 시전 완료가 성장 경계와 겹치고 후딜이 0인 경우에도, 미처리 시전을 둔 채 무료 파밍하지 않는다.
- 같은 시각에는 완료/강화 만료, 시전 시작, 기본 공격 순서로 처리한다. 동순위 참가자는 교전 시작 시 경기 난수로 정한 순번을 사용한다. 이 동시성 순서는 원작 서버 구현을 확인한 결과가 아니다.
- 개인별 행동으로 분리하면서 팀 집중 표적이 매번 초기화되던 문제도 수정했다. 같은 지역의 팀원들이 유효한 집중 표적을 다음 행동까지 공유하며, 죽거나 떠난 표적은 다시 고른다.

## 주요 연결 파일

- `client/src/app/simulation/_lib/characterCastRuntime.js`: 선택·시전·취소·강화 상태와 사건.
- `combatTimingRuntime.js`, `phasePvpActionLoopRuntime.js`: 개인 시각 예약과 실제 실행 순서.
- `characterSkillRuntime.js`, `phaseCombatEncounterRuntime.js`, `phaseCombatDamageRuntime.js`: 준비한 스킬의 실제 효과/피해 적용.
- `teamCombatRuntime.js`: 개인 공격 사이의 팀 표적 유지.
- `phaseActorActionPipelineRuntime.js`, `survivorLifecycleRuntime.js`: 시전 중 성장/부활 경계.
- `teamObserverRuntime.js`, `SimulationTeamObserverPanel.js`: 현재 시전/강화와 취소 사유 표시.

기존 `applyCharacterSkillOnBasicAttack` 내보내기는 호환/독립 검사 용도로 남았지만 제품 전투의 호출 경로에서는 제거했다. 모든 별도 전투 경로의 이전 API/규칙 감사가 끝났다는 뜻은 아니다.

## 통제 검사

`client`에서 `node ./scripts/check-character-casting.mjs`: **28/28 통과**.

- 1.25초 시전은 101.25초에 처음 피해를 주고, 0.25초 후딜 뒤 기본 공격은 101.5초부터 실행된다. 이전 프레임에는 선행 피해가 없다.
- Q와 W가 순차 시전된다. 공격 간격이 10초인 참가자도 1.25초 쿨다운 스킬을 기본 공격 사이에 다시 시전한다.
- 시전 중 짧은 기절/침묵, 이동기만 막는 속박, 사망·지역 이탈·대상 지정 불가 취소와 무적의 차이를 검사한다.
- 무적인 주 대상이 주변의 피해 가능한 광역 대상을 함께 보호하지 않는다. 피해 사건의 시각과 시전 ID도 확인한다.
- 지원 회복/보호막은 발동 전에는 없고, 사망한 지원 대상을 되살리지 않으며 아군 피해 사건을 만들지 않는다. 1.25초 보호막은 101.25초에 생겨 102.5초에 만료된다. 예전 지속 단위 배수나 최소 2초 연장은 없다.
- 강화 준비/실제 타격/새 표적/빗나감/재사용 단계/독립 만료를 검사한다.
- 순수한 선택, 중복 시작/완료 차단, 저장/다음 페이즈/부활, 더 긴 잠금 보존, 성장 경계 중복과 실제 무료 파밍 차단을 검사한다.
- 실제 상태에서 만든 관전 모델은 프레임을 변경하지 않고 시전 중과 대상 팀의 취소 사유를 표시한다.

기존 시간 26개 검사의 시전 기대값도 실제 별도 발동으로 바꾸고, 실제 3대3의 개별 공격 사이에 집중 공격이 유지되는 조건을 추가했다. 팀 지원/상태 검사는 즉발 스킬을 명시적으로 선택·발동한 뒤 기본 공격하는 방식으로 고쳤다. 피해/행동 제한을 삭제하거나 합격 조건을 낮춘 변경이 아니다.

## 남은 범위

- 기본 게스트의 Q/W/E/R 부재를 해결할 오프라인 스킬 데이터/입력 경로와 사용자 선택 연결. 출처가 있는 개별 정의와 시험용 가상 스킬을 구분해야 한다.
- 미터 단위 거리·공격 사거리·시야·접근/추적·투사체. 현재 같은 지역과 기존 추상 사거리 판단은 실제 거리 판정이 아니다.
- 전체 CC/면역 및 방해 효과 저항, 개별 이동기/정신 집중의 예외, 고유 자원, 고정 공격 속도, 일반/궁극기/전술 쿨다운 감소와 고정 쿨다운 예외.
- 전술·무기 스킬의 독립 시전과 사냥·차원의 틈 등 특수 피해/시간 경로 감사. 현재 캐릭터 스킬 예약과 같다고 가정하지 않는다.
- 새 스킬 선택은 현재 교전 중인 참가자를 대상으로 한다. 비전투 중 스킬 AI, 모든 캐릭터의 애니메이션/캔슬/충전 규칙은 포함하지 않는다.
- 세계의 모든 상태 임계점이나 지속 피해 사망의 수학적 순간을 각각 예약한 것은 아니다. 상태/이동 변화는 기존 세계 진행 및 전투 행동 경계에서 관측한다.
- 폭넓은 편성/난수에서 성장·합류·후퇴/집중 동선·종료 분포, G5.2 재편성/전략 비교, G5.3 실제 사용자 이해/재미 평가.
