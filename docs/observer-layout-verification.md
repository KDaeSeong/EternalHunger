### 지도 선택 입력 확인의 한계

자동 `selectOption`은 3초 응답 한도를 넘겼고, 당시 화면 관찰은 이전 선택으로 남아 있었다. 새로고침/새 탭에는 저장된 새 지도가 반영됐다. 새 페이지에서 실제 드롭다운을 열고 키보드로 내장 지도를 선택한 뒤에는 새로고침 없이 선택값/지도/하이퍼루프 12 반영을 확인했다. 자동 선택 실패를 데이터 손실 또는 지도 기능 고장으로 단정하지 않는다.
