## 2026-10-09 전술 효과와 시작 입력 경계 보강

시작 조건 비교는 지도·참가자 설정뿐 아니라 아이템 카탈로그·키오스크·드론·초기 월드와 분류되지 않은 실제 HP/위치/가방/예산도 표시한다. 전술 한 개만 바뀐 것처럼 무관한 초기 상태 변경을 숨기지 않는다. 직접 전술 합계는 유효한 발동 영수증의 실제 회복·HP 비용·전술 단계 차단·추가 원피해·이동을 사용하며, 미기록은 효과 0과 구분한다. 공격 원피해는 최종 HP 피해나 우승 인과가 아니다. 도주·추격과 지속 효과 전체는 이 합계에 포함하지 않는다.

현 저장 수정 엔진 `086cfa60…`에서 직접 비교 18개·새 전술 25개·전략 계약 17개와 인접 집중 검사가 통과했다. 전술 기록은 실제 클라이언트/서버 compactor 왕복으로 확인하며, 전체 재경기는 로컬 원본이 담당하고 계정 로그의 기존 마지막 사건 상한은 유지한다. 저장 직렬화 수정 전 `faadf968…`의 seed 2202 기준/편성 후보는 각각 두 번 실제 완주해 같은 조건의 사건·프레임·최종 상태·난수가 일치했지만 후보의 변경 동료 협력 노출이 없어 비교 명령 종료 2를 유지했다. 완주·재현과 전략 노출·인과는 별도 판정이다.

구체적인 실행 ID·수치·과거 엔진 경계는 [전술 실효과와 전략 비교 검증](tactical-effect-strategy-evidence-2026-10-09.md)에 기록한다. 이 추가 검사는 현재 공개 사이트·실제 로그인 저장·전경 배속·사람의 가독성/재미/재경기 의향 합격을 뜻하지 않는다. 파생 팀 명단 변화의 보수적 표시와 더 넓은 입력/실제 양측 전술 발동 비교는 남는다.

## 목적

완료한 경기를 그대로 재현하는 G5.1과 달리, G5.2는 보관된 시작 조건을 복사한 뒤 참가자 편성·전술·무기·스킬·능력치·지도·규칙·시드를 바꾸어 **새 경기**를 만드는 흐름이다. 두 경기의 입력과 실제 결과를 함께 제시하되 한 경기의 상관관계를 인과관계로 과장하지 않는다. 게스트 로컬 경기는 로그인 없이 이 기능을 사용한다.

## 제품 흐름

1. 경기 결과 화면 또는 경기 보관함에서 `편성·전략 바꿔 새 경기` / `조건 복사·변경`을 선택한다.
2. 보관된 참가자·초기 월드·지도·규칙·시드를 별도 초안으로 복제한다. 원본 저장 기록은 수정하지 않는다.
3. 동일 재경기 잠금을 적용하지 않으므로 시작 전 편성·전술과 허용된 경기 조건을 편집할 수 있다.
4. 시작하면 재경기가 아닌 새로운 경기 입력을 확정하고, 완주 시 별도 기록으로 저장한다. 기존 기록의 승리·보상 중복 차단 규칙을 새 경기에는 잘못 적용하지 않는다.
5. 경기 보관함에서 서로 다른 두 기록을 `비교 기준`과 `비교 대상`으로 골라 조건 및 결과 차이를 읽는다. 진행 중 경기에는 기록 교체와 비교 선택을 막는다.

## 비교 계약

시작 조건은 다음을 구분한다.

- 난수 시드, 지도 ID와 세부 지역 규칙, 경기 설정
- 팀 수의 요약과 참가자 추가·제외·팀 이동
- 참가자별 이름, 전술 스킬, 무기, 역할, 특성, 목표 장비, Q/W/E/R 구성과 레벨, 기본 능력치, 목표 장비 구성
- 팀 편성 요약은 참가자별 변화와 같은 사실을 두 번 센 것으로 취급하지 않는다.
- 객체형 설정과 구성은 `기준 세부값 → 변경 세부값`, `기준 구성 → 변경 구성`으로 양쪽을 구별한다. 같은 이름의 지도에서 세부 규칙만 바뀐 경우도 숨기지 않는다.

결과는 저장된 최종 프레임과 의미 사건에서 다음을 읽는다.

- 우승 팀, 경기 시간, 최종 생존자와 탈락자, 총 킬
- 제작·사냥 결산, 팀 교전·팀원 공격·팀 공격 피해, 열세 후퇴
- 공유 자원 획득·고갈 재계획, 차원의 틈 승리

판정 문구는 다음 경계를 지킨다.

- 시드가 다르면 결과 차이를 편성·전략만의 영향으로 단정하지 않는다.
- 시드와 기록된 시작 조건이 모두 같은데 결과가 다르면 전략 효과가 아니라 재현 불일치로 다룬다.
- 같은 시드에서 한 조건만 바뀐 경우에도 한 경기로 인과를 확정하지 않는다.
- 여러 조건이 함께 바뀌면 어느 변경이 결과를 만들었는지 분리할 수 없다고 표시한다.
