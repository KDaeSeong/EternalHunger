# 2026-10-07 순차 작업 검증

기준은 PR #12가 병합된 main `3f34c66e95089d06998fd45b59a7277b8409aba5`다. 이번 변경은 [PR #13](https://github.com/KDaeSeong/EternalHunger/pull/13)에서 검토한다. 아직 main에 병합한 결과가 아니다.

## 수정한 동작

1. **이미 가진 재료의 목표 교환을 놓치는 결함을 수정했다.** 운석과 3Cr를 가진 캐릭터가 생명의 나무를 요구하는 3Cr 레시피를 완성할 수 있는데도 비싼 직구만 검사해 목표를 포기하는 조건을 재현했다. 실제 보유 ID의 생나→운석, 운석→생나, 포스 코어→미스릴 교환을 직구 전에 검사한다. 개인 목표, 공동 구매 견적, 실제 정산이 같은 교환을 선택한다. 보유 후보와 레시피의 명시 ID를 우선하며, 제작비·남은 필수 재료·중간 가방 수용량·판매 정책을 보존한다. 목표에 유효한 교환은 임의 구매 확률 때문에 다시 누락되지 않는다.
2. **긴 팀 판단을 팀 단위로 나눴다.** 운영 브라우저에서 `growth.teamCoordination` 한 번이 최대 211.3ms인 표본을 찾았다. 8팀의 판단을 한 덩어리로 실행하던 부분을 팀 사이에서 양보할 수 있는 generator로 바꿨다. 한 팀의 판단은 원자적으로 유지하며 팀 순서, 공유 스냅샷, 난수와 결과는 보존한다. 동기 호출은 같은 generator를 끝까지 실행한다. 취소 시 남은 팀 판단도 닫는다. 한 팀 자체의 작업 시간이나 전체 브라우저 성능 합격을 보장하는 변경은 아니다.
3. **성능 측정의 가시성 근거를 보강했다.** 시작·종료가 둘 다 `visible`이어도 중간에 탭이 숨겨졌을 수 있었다. 이제 `visibilitychange`를 관찰해 visible/hidden/unknown 구간과 전환 횟수, 전체 측정 가시성 여부를 기록한다. 이벤트 API가 없으면 가시성 합격을 표시하지 않는다. 카운터만 유지하며 중지·자동 중지·재시작 때 리스너를 해제한다. 기존 v2 결과의 새 필드 부재를 전체 가시성 통과로 해석하지 않는다.

게임 내 음식 판매 정책은 유지한다. 물은 전송 드론에서만 구매하며, 음식은 키오스크·전송 드론에서 제외한다. 커스텀 재료는 실제 작성된 판매 재고가 있을 때만 취급한다.

## 1–3. 자연 조달, 커스텀 제작, 팀 전략

`check:natural-procurement-matrix`는 정상 시작 입력을 생성하고 실제 전체 경기를 실행한다. HP·가방·Cr·판매 목록·중간 경기 상태를 주입하지 않는다. 완료 영수증의 개인 자금 보존, 음식 정책과 관전 연결을 검사하며, 공동 구매 발생이 0건인 실행도 그대로 보고한다.

이는 서로 다른 **11조건**의 관찰과 기본 3조건의 수정 후 재실행이다. 공동 구매 목표는 세 실행 묶음 모두 0건이다. 자연 공동 구매→실제 교환/구매→유료 제작→장착의 수용 조건은 **미충족**이다.

기준선 9경기에는 실제 키오스크 정산 199건, 영수증 재료와 이후 소모 로그를 연결한 제작 165건, 같은 제작 아이템의 장착 관찰 163건이 있다. 이 연결은 이후 동일 재료 소모에 대한 연결이며 유일한 인과 귀속이나 공동 구매 건수가 아니다. 기본 레시피의 제작비는 0Cr이므로 이를 자연 유료 제작 증거로 계산하지 않는다. 추가 1102/1103에서는 정산 19/18건, 제작 연결 16/18건, 장착 관찰 15/18건이다.

정상 1101의 읽기 전용 20초 간격 프레임 진단에서는 조달 견적 3건이 있었지만 모두 행동·사냥 대기 조건에 걸린 표본이었다. 전체 표본의 행동/사냥 대기 195, 모이지 않음 61, 초반 성장/회복 33, 생존 월드 팀원 한 명 130이다. 이는 실제 planner 호출의 전수 거절 기록이 아니다. 정상 보호 조건을 지워 성공을 만들거나 난수를 소비하지 않았다.

기준선 9경기의 합류 도착은 461건, 사냥 이어받기 13건, 보스 보상 완료 20건이다. 다시 만난 분리 구간의 최댓값은 조건별 60–188초다. 후퇴 방향 반전은 두 조건에서 1/2건이며 표본 간격은 40/54/60초다. 이를 무한 후퇴 버그나 전략 적절성 합격으로 단정하지 않는다. 경기 종료 시 아직 분리 중인 기록은 우측 검열이며 새 보고서 필드 `isolationCensoredAtMatchEnd`로 구분한다.

커스텀 제작 33, 커스텀 장비 10, 소비 효과 29, 성장 계획 33, 수용량 15, 후반 성장 29개의 기존 검사를 재확인했다. 새 목표 교환 6그룹은 세 교환, 동명·보유 ID, 개인/공동 자금, 필수 재료 보호, 부족 제작비와 다단계 레시피, 가방 한계의 양·음성 조건을 포함한다. 기존 공동 구매 43개는 실제 개인 결제·교환·3Cr 제작·장착·저장/관전 연결의 통제 사례다. 기능 검사와 자연 발생 빈도는 구분한다.
