# 수면·변이·제압·경직의 실제 행동 연결

기준일: 2026-09-05. G2.3 중 네 상태의 처리 단계이며 전체 목표 완료가 아니다. 사용자 제공 참고자료의 행동 의미를 현재 전투 실행기에 연결한다. 사용자 상태 스킬 편집 및 원작 전체 실험체·이동기 구현은 별도 잔여다.

후속 상태: 사용자 상태 스킬 입력/저장/AI/실제 발동 연결은 `character-status-skills-verification.md`로 진행했다. 이 문서의 84087은 중단 뒤 실행 핸들이 사라져 최종 종료 코드를 회수하지 못했다. 아래 실행 중 표기는 당시 기록이며 전체 통과를 뜻하지 않는다. 최신 전체 검사는 후속 문서의 별도 실행을 따른다.

## 구현 범위

| 상태 | 실제 처리 | 확인 경계 |
| --- | --- | --- |
| 수면 | 이동·평타·스킬 제한. 첫 양의 직접 타격에서 추가 피해와 해제. 여러 피해 묶음 중 한 번만 적용 | 피해 미리보기는 수면을 소비하지 않는다. 빗나감·무적·대상 지정 불가·0 피해·사망자는 해제하지 않는다. 기존 보호막이 전부 흡수해도 피격 해제 |
| 변이 | 평타·스킬 제한과 감속 보행. 실제 사냥 경로도 보상/재고 소비 전에 차단 | 이동 자체를 금지하지 않는다. 유효한 변이 중 생존자 초상을 양 표식으로 바꾸며, 면역으로 무시되는 변이는 외형도 바꾸지 않음 |
| 제압 | 행동 제한, 현재 지역 내부 이동 계획 취소, 시전 중단 | 면역으로 거부/무시된 제압은 이동을 취소하지 않는다. 보호 종료 뒤 남은 제압이 활성화되면 취소. 저장/복원된 이동도 취소. 원작 개별 돌진기 전체 구현을 뜻하지 않음 |
| 경직 | 행동·신규 대상 지정·직접 피해·기존 지속 피해 차단. 금지구역 목걸이 카운트 정지 | 기절이나 일반 무적과 별개. 만료되는 소수 시간까지만 정지하고 안전지대와 중복 계산하지 않음. 보호 중 0 카운트도 폭발하지 않으며, 보호가 끝나면 정상 판정 |

모든 상태는 기존 유효 효과·면역·정화·시간 경계를 공유한다. 시전 중 수면이 걸렸다가 같은 타격에서 즉시 깨더라도 이미 발생한 시전 중단은 되돌리지 않는다. 취소 표시는 기존 시전 취소 사건을 사용한다.

## 명시적 프로젝트 규칙

- 제공 자료에는 수면 추가 피해량과 변이 감속량이 없다. 수면의 `wakeDamagePct` 기본값은 0.2(20%), 변이의 `moveSpeedBonus` 기본값은 -0.5(-50%)이다. 효과 데이터에서 조절 가능하며 원작 확정 수치라고 표기하지 않는다. 사용자 편집 화면의 해당 입력은 아직 없다.
- 수면 추가 피해는 이미 방어/증폭 계산된 직접 타격의 비율을 정수 반올림하여 더한 뒤 보호막을 적용한다. 작은 타격의 추가분은 반올림 결과 0일 수 있다. 명시적 0을 보존하고 비율은 0~1로 제한한다.
- 기본 공격·캐릭터/전술 스킬 피해·광역·무기 후속 피해는 같은 타격 확정 함수를 쓴다. 실제 HP 감소량만 기존 흡혈·기여도·처치 판정에 전달한다. 추가 피해를 과잉 피해나 보호막 피해만큼 HP 감소로 부풀리지 않는다.
- 수면 해제는 방어 반응/보호막 처리 뒤 확정한다. 이미 붙은 지속 피해 및 환경 피해는 이 프로젝트에서 직접 공격으로 분류하지 않아 수면을 깨우지 않는다. 이 선택은 원작의 모든 예외를 확인한 결과가 아니다.
- 변이 감속은 기존 이동 속도 보정 합산/하한 규칙을 사용한다. 양 표식은 이 프로젝트의 관전 표시이며 원작 특정 스킬의 외형을 복제한 것이 아니다.
- 경직 중 효과 지속 시간과 재사용 대기시간은 흐른다. 금지구역 밖 목걸이 회복은 기존 규칙을 유지한다. 제압이 이미 완료된 지역 간 전송을 되돌리지는 않는다.

## 실패 재현 및 수정

1. 네 상태 모두 분류명만 존재하여 실제 행동을 막지 않았다. 새 검사 최초 실행은 0/4 실패였으며 상태 메타와 실제 선택/피해/이동 경로를 연결했다.
2. 변이는 전체 행동 금지로 처리하면 보행까지 사라진다. 평타·스킬만 차단하고, 별도로 사냥 보상 경로의 허점을 막았다.
3. 타격 피해 미리보기에서 수면을 소비하면 여러 피해 묶음과 보호막 판정이 어긋난다. 실제 HP 반영 시점으로 모으고 첫 피격 한 번만 해제하도록 했다.
4. 제압 중 이동을 일시 정지만 하면 만료 후 옛 이동이 재개된다. 유효 제압에 이동 계획을 폐기하고, 저지 불가 만료 경계 및 JSON 복원도 검사했다.
5. 경직과 안전지대의 보호 초를 더하면 시간이 과보호된다. 같은 구간 시작에 걸친 보호의 최댓값을 사용한다.
6. 실제 카드 화면에서 흰 카드 위 상태 설명·체력 등이 흐리고 타이머 대비가 약한 것을 확인했다. 생존자 카드의 기본 글자색과 타이머 배경색을 명시하고 수정 화면을 재확인했다.
7. 첫 24인 시험은 초기 상태만 부여한 일반 경기여서 피격 해제가 한 번도 발생하지 않았다. 진단 재실행에서 0초 후퇴·지역 이탈과 첫 피해 198.25초를 확인했다(수면은 8.5초에 만료). 성장 시계만 지연해도 접촉 조건을 보장하지 못했다. 경기 규칙이나 통과 조건을 낮추지 않고 기존 교전 설정 함수를 사용한 명시적 초기 교전 상황을 저장 입력에 포함했다. 그 뒤 실제 해제 2건과 완주·재경기 일치를 확보했다. `--diagnose-opening`은 원래 비접촉 조건을 재현하는 별도 진단이며 합격 시험을 대체하지 않는다.

## 실제 화면 확인

`scripts/preview-status-protection.mjs`를 확장하여 실제 전투 실행기·금지구역 시계의 프레임을 실제 생존자 카드 및 팀 관전창으로 렌더링했다. 제품에 검사 전용 경로를 추가하거나 사용자 저장 자료에 효과를 주입하지 않았다.

- 변이 101초: 양 외형, 감속 보행 설명, x=5.8 및 이속 1.8m/s 표시 확인. 수정 후 체력·설명·카운트 가독성을 스크린샷으로 확인했다.
- 경직 101초: HP 1000, x=4.0 유지, `10/30s · 정지`와 행동/피해/대상 지정 제한 설명 확인. 102.25초에는 경직 배지와 정지 안내가 없어지고 카운트가 다시 감소했다(실제 상태 9.75초, 화면 정수 9초).
- 수면 100초: HP 1000, 행동 제한 표시. 100.25초의 직접 타격 이후 HP 880, 수면 제한 해제, 최근 사건의 추가 피해 20(보호막 적용 전) 문구 확인. 마지막 문구 수정도 새 화면에서 확인했다.
- 제압 101초: x=4.0 유지, `행동 불가 · 진행하던 이동 취소` 확인.
- 검사용 서버와 탭을 닫고 기존 사용자 탭/편성/보관함은 보존했다. 이 통제된 컴포넌트 검사는 최종 프로덕션 제품에서의 일반 원본 경기·보관함 재경기와 구분한다. 후자는 아직 이 엔진에서 하지 않았다.

## 다음 작업

실행 중인 최종 전체 검사(84087)의 결과를 먼저 확인한다. 24인 상태 경기/재경기는 통과했으므로 결과가 없는 것으로 되돌리지 않는다. 그 뒤 사용자 Q/W/E/R에서 실제 상태 부여·보호·정화를 작성하는 경로와 나머지 시야/쿨다운/고유 자원/특수 경로를 연결한다. 현재 게스트 저장은 피해·회복·보호막·능력치가 없는 상태 전용 스킬을 거부하고 상태 효과 필드를 보존하지 않으므로, 컴파일된 정의·저장 검증·실제 스킬 발동·편집 화면을 함께 연결해야 한다. G1~G3 전체 지급 감사·파밍/합류/생존 균형, G5.2 편성·전략 비교, G5.3 경험자의 실제 이해·재플레이 의향 평가를 포함한 전체 목표는 미완료다.
