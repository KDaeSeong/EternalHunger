2026-09-27. 최초 사냥자가 후퇴·사망·지역/전장 이탈하면 현장의 같은 팀 대원이 기존 전투를 이어받는다. 원격 지원, 모든 동물의 공동 사냥, 보스 능력치/보상 변경은 포함하지 않는다.

## 구현과 경계

- 기존에는 최초 사냥자의 이탈로 보스 점유와 전투가 해제됐다. 수정 전 통제 검사에서 이어받기 사건 0건(기대 1건)을 재현했다.
- 같은 지역의 살아 있는 동료 중 기존 공동 사냥 참여자를 먼저 고른다. 같은 조건에서는 고정 ID 순서이며 추가 난수를 쓰지 않는다. 저체력/회복, 초기 파밍, 다른 사냥·시전, PvP, 강제 제어, 금지구역·차원의 틈 경계는 유지한다.
- 새 보스를 만들지 않고 기존 대상/전투/보상 예약을 한 명에게 이전한다. HP, 위치, 지속 효과, 공격 대기시간, 개인 시전·쿨다운을 초기화하지 않는다. 보스는 다음 실제 행동부터 후속 대원을 공격하며 이전 사냥자를 향한 추적만 해제한다.
- 이전 대원의 사냥 시전은 취소하되 쿨다운은 환불하지 않는다. 이어받은 동료의 진행 중 지원 시전은 유지한다. 콜백이 실행될 때도 이미 후속 대원이 단일 전투를 소유한다.
- 공격/피격 기여도와 이미 지급한 숙련도를 각 대원별로 추적한다. 크레딧과 전리품은 실제 처치 때 한 번만 정산하고 기존 동료 제작 수요 분배를 유지한다.
- 같은 행동 주기에 다른 사냥을 마친 후속 대원에게 보스 보상이 누락되는 추가 실패도 재현·수정했다. 완료한 실시간 전투 ID로 정산을 구분한다. 동료가 마무리할 때 후속 대원이 기절 중이어도 전리품은 받지만 기절 중 즉시 제작하지 않는다.
