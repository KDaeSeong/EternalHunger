# 성장 재료 경로의 위험 판단

2026-11-15. 실제 이동 단계에서 가까운 재료 공급지에 압도적인 적이 있어도
거리·필요량·구역 이름만으로 그곳을 선택했다. 같은 명단을 받은 기존 안전
경로 함수는 그 공급지를 거절했고, 안전한 다른 공급지는 허용했다.
일반 목표 선택기가 이미 안전한 곳을 골랐다는 뜻은 아니다. 그 함수에는
적 명단 입력이 없으며, 누락은 성장 이동의 실제 위험 판단이었다.

성장 이동에 기존 안전 경로의 전력 압력 기준을 적용했다. 전달받은 같은
전투 공간의 현재 명단을 사용하며 새 시야·정보나 밸런스 수치를 추가하지
않는다. 한 번의 유한 단방향 BFS로 공급지와 중간 구역을 확인하고,
기존 거리·필요량·이름 순서로 안전한 공급지를 고른다. 실행기에는 안전한
인접 구역만 넘기므로 위험한 지름길로 다시 계산하거나 순간 이동하지 않는다.

모든 재료 경로가 위험하면 원래 목표를 보존하고 현재 구역에서 대기한다.
`no_safe_path`와 기존 `growth_blocked` 표시를 함께 사용하여 위험한 목표
기억이나 일반 무작위 이동이 다시 활성화되지 않게 한다. 다음 행동은 적의
이동·생존·아군·재고·금지구역을 다시 읽는다. 자료는 동기 결정 안에서만
재사용하며 프레임·대원·전역 캐시에 남기지 않는다.

첫날 아침의 PvP 유예, 현지 제작, 금지구역 탈출·현재 교전 후퇴·회복·확정
팀 이동·최종 안전구역의 기존 우선순위는 유지한다. 첫날 밤부터는 원래
PvP 규칙에 맞춰 위험 경로 판단이 적용된다. 공급지 자체가 없는 경우의
기존 재계획을 별도의 오류로 취급하지 않는다. 원재료·돈·제작비·능력치는
지급하거나 수정하지 않는다.

## 검증 범위

신규 `npm run check:growth-safe-movement`는 실제 이동 단계 15그룹을 검사한다.
동률·먼 안전 공급지, 위험 중간 구역·4개 간선 우회, 모든 경로 위험 시 대기,
다음 행동의 위협·재고·금지 갱신, 다른 전투 공간·아군·사망자, 허용되는
전력비, 아침 유예와 밤의 차이, 기존 행동 우선순위와 재료·비용 보존을
고정된 기대 구역·목적지로 검증한다. 수정 전 실제 소스는 7/15, 수정 후는
15/15이며, 별도 원본 모듈 로딩 실행에서도 같은 8개 실패를 재현했다.

독립 검토의 5그룹은 방향 그래프의 끝 구역, 위험 지름길 우회, 위협 갱신,
금지된 대안, 38개 간선 경로를 확인했다. 두 생존 인물의 전투력은 결정당
각 한 번 계산했다. 이는 실제 전경 FPS나 전체 성능 합격을 뜻하지 않는다.

이동·팀·성장·관측·조달·예약·검증 지문·린트와 기존 첫날 밤 2조건을 포함한
19명령이 같은 1,620개 소스 입력에서 통과했다. 두 경기 조건은 기존 시드와
기한을 유지한 원 실행·동일 재경기이며 전체 경기 종료 검사가 아니다.
`--expanded`, 실패한 고정 편성 8회, 5501/5502·HF4 표본은 실행하지 않았다.
새 엔진은 `309ff261…`이다. 같은 1,620개 입력과 엔진을 유지한 프로덕션
빌드 `fptQgMtIzuQfcZHoEN12P`와 빌드된 Worker 첫 단계도 통과했다. 공개 실제
경기·재경기는 푸시 후 별도 확인한다.

이번 증거는 알려진 전력 위험을 피하는 실제 성장 이동의 기능 범위다.
광범위 커스텀·자연 전략 균형·전체 시대·전경 관전·사람 평가와 원래
G1~G5 및 다른 게임의 전체 목표는 각각의 추가 증거로 판정한다.
