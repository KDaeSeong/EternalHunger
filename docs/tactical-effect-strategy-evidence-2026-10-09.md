# 전술 실효과와 전략 비교 검증

치유의 바람이 전투에서 즉시 회복량을 읽지 못하던 결함을 수정했다. 직접 전투 발동의 실제 회복·HP 비용·전술 단계 피해·이동·쿨다운 근거를 남기고, 보관함 비교와 팀 관전 설명에서 최종 HP 피해나 승리 원인과 구분한다. 전술·편성 비교는 두 조건 모두 실제 발동·팀 행동이 관측되어야 합격하며, 관측되지 않은 경기는 버리지 않는다. 전체 G1~G5 목표는 활성/미완료다.

## 실제 게임 수정과 기록 범위

전투 경로는 치유의 바람 카탈로그의 `healCap`을 읽지 않고 `selfHeal`만 읽었다. 수정 전 실제 함수 검사에서 HP 40의 즉시 회복 결과가 40이었고 기대값 62와 달라 실패했다. 수정 후 같은 현재 함수에서 레벨 1은 40→62, 레벨 2는 40→70이다. 지속 회복 효과도 유지한다. 회복 감소 50%일 때 40→51, 최대 HP 45일 때 40→45를 확인한다. 사망·침묵·HP 46·쿨다운 중에는 회복이나 새 발동을 만들지 않는다. 예산·재료·장비를 지급하지 않으며 현재 발동 기준 HP 45도 바꾸지 않는다. 이번 수정은 시전자 회복 경로이며 원작의 모든 범위 회복을 구현했다는 뜻이 아니다.

방어 전술은 기존 보호막 흡수량과 새 전술의 차단량을 나눠 기록한다. 아티팩트 치명 방지 분기도 발동 사건을 남기며, 정확한 공격자·방어자·공유 시각의 실제 `damage` 사건에 연결해 HP 감소를 확인한다. 공격 전술의 추가 원피해는 이후 방어·보호막·HP 적용 전의 수치다. 비교 화면은 직접 기록된 발동만 합산하고, 누락·잘못된 근거는 효과 0이 아니라 미기록으로 표시한다. 도주·추격 전술과 지속 회복 전체는 이 합계 밖이다.

손상된 저장 기록의 `lethalPrevented=true`도 그대로 믿지 않는다. 살아 있는 HP, 기존 보호막 적용 뒤 남은 피해가 HP 이상인 조건, 통과 피해가 HP−1인 관계를 모두 요구한다. 수정 전 새 검사 19개 중 이 항목이 실제로 실패했다. 정상 HP 1, 기존 보호막 부분 흡수 뒤 치명 방지, 치명이 아닌 방어는 실제 발동·HP 적용에서 출발해 검사한다. 정상 전술 발동이나 피해 계산 규칙을 이 판독 보강으로 바꾸지 않는다.

## 비교 검사의 보호 조건

- 매번 현재 게스트 입력·지도·카탈로그·규칙으로 전체 시작 입력을 새로 만든다. 과거 결과 JSON이나 이 보고서는 검사 입력·정답이 아니다.
- 전술 비교는 해오름 한 명의 전술만 바꾸며 원 입력 복원으로 다른 HP·위치·장비·예산 등의 변경을 거부한다. 두 설정 전술 모두 유효한 직접 발동이 있어야 한다.
- 편성 비교는 같은 팀 슬롯의 백로와 윤슬을 다른 팀으로 교환하고, 영향받은 팀원들의 명단 ID·이름·크기를 재계산한다. 두 팀 이동과 12개 파생 명단 변경을 따로 남기며 무관한 초기 상태는 유지한다.
- 편성 노출은 교전 피해를 주고받았다는 사실만으로 합격하지 않는다. 변경 동료가 같은 교전 편성에 있고 실제 팀 공격의 HP 사건이 연결되거나, 변경 동료의 유효한 후퇴 엄호가 있어야 한다. 엄호 보너스 상한은 실제 생산 함수와 같은 0.24다. 0.25를 잘못 허용하던 검사 결함은 수정 전 실패를 보존하고 수정했다.
- 같은 조건을 적어도 두 번 실제 완주한다. 전체 사건·프레임 해시/수량·최종 상태·로그·종료·난수와 입력 불변성을 비교한다. 경기 완주와 비교 노출 합격은 별도 판정이다.
- 출력은 고유 경로에 먼저 만들고 완료한 실행을 순차 보존한다. Windows의 따옴표 전달로 출력 경로가 실패한 기록도 삭제하지 않는다.

윤슬의 여섯 표본은 실제 혼자 남은 교전 편성이다. 두 대원의 유효 HP 산술 위반은 0개였고, 후보의 HP 연결 불일치 거부도 0개다. 다만 동료 부재 검사가 HP 연결보다 먼저이므로 그 여섯 공격의 HP 연결 자체를 합격했다고 말하지 않는다. 백로의 비활성 사유나 윤슬의 동료 사망·이동 인과까지 이 표가 증명하지는 않는다. 기준 편성은 백로 1회·윤슬 6회의 변경 동료 팀 공격 연결을 통과했다. 따라서 단순 HP 사건만 확인하던 옛 검사는 이 후보를 거짓 합격시킬 수 있었지만, 현재 검사는 미통과를 유지한다.

## 완료로 승계하지 않는 관문

현재 엔진의 집중 검사·빌드와 별개로 단일 전체 `check:eternal-hunger`, 직접 발동이 있는 양측 전술 비교와 더 넓은 편성·커스텀 입력, 실제 전경 x1/x8/x32 및 연속 메모리, 지도 충실도·사람의 이해·재미·재관전 평가는 남는다. AI 초안 생성의 이전 API 키 실패는 성공으로 바꾸지 않으며 승인 없는 유료 재시도·계정 저장을 하지 않는다. 원 마커스 경기 파일이 없어 다른 입력을 그 경기의 정확한 재현으로 부르지 않는다.

편성의 파생 팀 명단 변경을 제품 비교가 별도 초기 상태 변화로 보수적으로 보여줄 수 있는 표시 경계도 남는다. 이를 제거하려면 무관한 HP·재료·예산·위치 변경까지 숨기지 않는 별도 계약이 필요하다. 도주·추격과 지속 효과의 전체 귀속, 관측되지 않은 활성 차례의 원인도 후속 범위다. 이번 작업은 기존 사용자 변경·다른 게임을 보존하며 푸시·공개 배포·전경 브라우저·계정 쓰기·추가 유료 호출을 포함하지 않는다.
