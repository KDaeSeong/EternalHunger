# 목표 장비 자율 성장 검증

검증일: 2026-09-04. 전체 목표는 `eternal-hunger-goal.md`이며, 이 문서는 성장 구현의 증거와 남은 범위만 기록한다.

## 이번에 바뀐 동작

- 실제 가방을 기준으로 목표 장비의 다단계 레시피를 역산한다. 이미 제작한 중간 장비의 원재료는 다시 요구하지 않는다.
- 한 장비의 제작 가지에 집중하여 재료를 확보한다. 필요한 재료가 현재 지역에 있으면 머물고, 없으면 안전하게 연결된 가까운 공급 지역으로 이동한다. 막힌 목표는 다른 미완성 목표를 검토한다.
- 첫날 무조건 이동, 고정 탐색 횟수, 날짜 경과가 이 성장 판단을 덮어쓰지 않는다. 금지구역 이탈·위험 회피·회복은 여전히 우선한다.
- 같은 장비 부위의 중간 재료 여러 개를 가방 용량 안에서 보관하고 실제 조합 시 소비한다. 다른 무기 종류의 재료는 보관하되 자동 장착 대상에서 제외한다.
- 제작 준비가 끝나면 구매나 추가 탐색보다 실제 조합을 우선한다. 판단용 미리보기는 실제 장비·가방·제작 제한 상태를 변경하지 않는다.
- 2지역 초반 경로를 찾지 못한 참가자도 목표 장비를 받는다. 기존에는 대체 경로만 받고 목표 목록이 비어 있었다.
- 준비된 팀원은 첫날에도 합류할 수 있다. 미완성 팀원을 날짜 기준으로 파밍에서 끌어내지 않는다.
- 실제 레시피 카탈로그가 있을 때 특수 재료 즉시 제작도 전체 재료를 소비한다. 특수 재료 하나를 임의 장비로 바꾸거나 숨은 전투 보너스를 덧붙이지 않는다.

## 자동 검사

`client`에서 `npm run check:growth-plan`을 실행한다. 총 14개 검사이며 전체 `check:eternal-hunger`에도 포함했다.

중간 재료 보존·소비, 동급 목표 장비 교체, 초반 지역 체류, 지역별 재료 제한, 안전 경로 재계획, 최단 이동, 제작 미리보기 격리, 가방 정리, 중복 재료 수량, 순환 레시피 거부, 준비도 기반 합류, 특수 제작 재료 부족 거부/실소비, 24인 자율 성장 검사를 포함한다.

최종 수정본에서 `npm run check:eternal-hunger` 전체 종료 코드 0을 확인했다. 새 성장 검사 14/14, 기존 팀 전술 검사 20/20, 시간축 검사 10/10을 포함하며 게스트·부활·편성·지도·무기·기술·피드백·음원·런타임 정적 검사와 프로덕션 빌드가 모두 통과했다. `git diff --check`도 종료 코드 0이며 기존 파일의 줄바꿈 안내만 있었다.

### 성장만 분리한 통제 검사

실제 게스트 774개 아이템과 초기 편성·이동·탐색·제작 실행기를 사용한다. 24명은 같은 훈련 팀이며 PvP·금지구역·월드 보스는 제외한다. 위치 강제 변경, 가방 무제한화, 재료 리필, 장비 지급은 하지 않는다. 20초 간격으로 행동한다.

| 난수 시작값 | 완성 인원 | 제작 횟수 | 이동 횟수 | 최초~최후 완성 경기 시간 |
| --- | ---: | ---: | ---: | --- |
| 1101 | 24/24 | 369 | 215 | 340~500초 |
| 2202 | 24/24 | 372 | 187 | 340~520초 |
| 3303 | 24/24 | 365 | 194 | 340~540초 |

재실행 시 `EH_GROWTH_SEED` 환경 변수로 난수 시작값을 지정한다. 이는 성장 경로가 실제로 끝까지 이어진다는 증거이며, 실제 경기에서 모든 참가자가 완성한다는 뜻이 아니다.

### 실제 경기 실행기 검사

`check-action-timeline.mjs`는 실제 24인 게스트 경기의 성장·전투·금지구역·부활·종료 처리를 실행한다. 표시 대기만 생략하고 서버 요청은 차단한다. `EH_MATCH_SEED`로 시작값을 지정한다.

| 난수 시작값 | 성장 행동 | 제작 이벤트 | 교전 | 완성 관측 인원 | 종료 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1101 | 1118 | 384 | 105 | 16/24 | 6일 밤 |
| 2202 | 1087 | 369 | 117 | 17/24 | 6일 밤 |
| 3303 | 1039 | 392 | 117 | 19/24 | 6일 밤 |

세 경기 모두 12개 단계, 시계 1230회, 서버 요청 0회. 각 실행의 시간 순서·사망 후 같은 단계 재행동 금지·설정 및 저장 중복 방지 등 10개 검사가 통과했다. 완성 인원은 이동 판단 당시 `growth_plan` 이벤트에서 관측한 서로 다른 참가자 수다. 순간 완성 직후 탈락한 참가자까지 포함하는 완전한 장비 이력 통계는 아니다. 제작 이벤트 수 또한 모든 특수 제작 경로를 포괄하는 통계로 확대 해석하지 않는다.

## 남은 검증과 구현

- 미완성 참가자의 원인을 탈락, 위험 회피, 회복 반복, 공급 차단, 제작 정체로 구분하는 진단.
- 지역 재료의 공유 재고·고갈과 그에 따른 재계획. 현재 기본 재료 공급은 유한 경쟁 자원이 아니다.
- 특수 제작 단위 검사는 통과했지만 전체 아이템 지급 경로 감사와 후반 목표 장비 계획은 별도 진행해야 한다.
- 세 경기 모두 같은 마지막 단계에서 끝났다. 이것은 자연스러운 경기 템포나 강제 결판 의존도 개선의 증거가 아니다.
- 팀 교전의 실질적 지원 효과, 진행 중 관전 UI 갱신, 설정/난수 저장·재경기, 실제 사용자의 반복 플레이 평가는 미완료다.
- 이번 변경은 실행기 자동 검사다. 브라우저 관전 검증이나 재미 합격으로 계산하지 않는다.
