# 이환·원신 캐릭터 1차 확장

오토체스와 무한 디펜스에 같은 12명을 추가한다. 기존 캐릭터와 저장 슬롯은 유지한다.

|---|---|---|---|
| 이환 | 나나리 | 5 / 사격 | 번개 연타 |
| 이환 | 사키리 | 2 / 지원 | 이상 제어·범위 둔화 |
| 이환 | 하토르 | 3 / 사격 | 중화기 관통 |

능력치, 역할과 스킬 효과는 각 미니게임에 맞춘 구성이다. 원작의 공식 전투 수치와 스킬 설명을 그대로 재현하지 않는다.

## 오토체스

캐릭터 32명, 기존 4개 학원과 헤테로 시티/티바트의 총 6개 세력으로 구성된다. 서로 다른 캐릭터 2명/4명에서 시너지가 강화된다.

- 헤테로 시티: 각 아군이 첫 스킬 사용 시 최대 체력의 12%/24% 보호막을 한 번 얻는다.
- 티바트: 모든 아군의 스킬 피해, 회복과 보호막 효과가 15%/30% 증가한다.
- AI는 새 대전에서 두 신규 세력을 선호하는 팀도 포함한다.
- 도감은 작품별로 얼굴, 비용, 역할, 스킬과 기본 능력치를 표시한다.
- 상점, 합성, 판매, 공용 기물 반환 규칙은 모든 작품에 똑같이 적용한다.

## 무한 디펜스

작품별 6명, 총 18명을 선택한다. 작품 탭을 바꾸어 캐릭터를 고르고 기존 8개 방어 거점에 배치한다. 지도에서 다른 작품의 캐릭터를 선택해도 작품 탭이 함께 바뀐다.

채굴 정원은 6명이다. 기존 6명 전체를 채굴할 수 있었던 상한을 유지하여, 명단 확장만으로 18명이 동시에 채굴하는 상황을 막는다. 거점 수, 기존 6명의 능력치와 강화 비용, 일반 웨이브와 보스 조건은 유지한다.

## 저장 호환성과 보존

저장 버전은 각각 kivotos-autochess-v2, infinite-defense-v2다. 기존 계정 슬롯 키 kivotos-autochess-main, infinite-defense-main과 기기 저장 키는 유지한다.

v1 읽기와 계정 불러오기를 지원한다. 오토체스는 기존 8팀·편성·상점·이전 기물 수량·난수·진행 중 전투 결과를 유지하면서 새 12명의 기물 풀만 추가한다. 디펜스는 기존 배치·투자·훈련·웨이브·적 상태를 유지하면서 새 12명의 기본 대기 상태를 추가한다. 기존 오프라인 채굴 규칙은 그대로 적용한다.

기기 저장을 처음 v2로 쓸 때 이전 v1 원문을 기존 키의 :legacy-v1에 한 번 보관한다. 손상된 v1, 일부만 섞인 형식, 지원하지 않는 미래 버전은 임의 추정으로 복원하지 않는다. 계정 저장의 버전 표기와 실제 본문 버전도 일치해야 한다.

## 공식 일러스트

신규 12명은 모두 공식 운영 서버에서 받은 원본이다. 생성 이미지나 팬아트를 사용하지 않았다.

- 이환: [공식 한국어 캐릭터 소개](https://nte.perfectworld.com/kr/main.html)의 모바일 캐릭터 포스터에서 얼굴을 잘랐다.
- 원신: [공식 사이트](https://genshin.hoyoverse.com/ko/)와 연결된 HoYoLAB 게임 기록 이미지 서버의 기본 캐릭터 아이콘을 사용했다.
- 신규 파일은 client/public/games/shared/crossover에 160×160 WebP로 보관한다. 12장 합계는 139,926바이트다.
- 원본 주소, 한국어 이름, 원본/결과 해시, 크롭 좌표와 가공 내역은 같은 폴더의 sources.json에 있다.
- 기존 블루 아카이브 21장과 출처 기록은 재사용한다.
