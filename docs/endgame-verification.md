# 최종 구역 축소와 실제 경기 종료 검증

기준일: 2026-09-05. G3.2의 종료 흐름 및 관련 G4 금지구역 표시 작업.

## 구현한 규칙

- 강제 위치 집결, 전투력/점수 비교에 의한 즉시 탈락, 전원 폭발 후 임의 생존자 부활을 제거했다.
- 일반 구역 폐쇄는 남은 도보 지역을 분리하지 않는 후보를 우선한다. 기본 루미아와 직선형 테스트 지도에서 연결성을 검사했다. 원래 단절된 사용자 지도에 새로운 길을 만들어 주지는 않는다. 연구소의 지정 폐쇄 규칙은 유지하며, 이전 폐쇄 지역을 다시 열거나 중복으로 계산하지 않는다.
- 6일 밤부터 현재 안전지역 중 최종 구역을 선정한다. 최대 두 곳에서 시작해 90초 뒤 한 곳, 시작 370초 뒤 전지역 폐쇄로 진행한다. 최종 구역은 팀 전투력/점수와 무관하게 선정하며 다음 페이즈에도 보존된다.
- 참가자는 실제 경로의 한 구간씩 이동하고 도보/하이퍼루프 이동 시간을 지불한다. 마지막 구역으로 미리 이동하거나 금지구역을 벗어날 수 있다. 기존 CNOT/블링크/넉백 같은 개별 장치·스킬 효과는 별도 규칙으로 유지한다.
- 구역 폐쇄 자체는 승자를 고르지 않는다. 기존 폭발 타이머가 경과하며, 폭발 타이머가 없는 규칙에는 초당 최대 체력 5%의 최종 구역 피해를 적용한다. 동시에 전멸하면 우승자 없는 결과로 기록한다.
- 초반 전멸 보호 부활을 고려한 공통 종료 판단을 사용한다. 마지막 팀이 남으면 그 시각에 멈추며, 화면 상태를 감시하는 별도 조기 종료 처리는 제거했다.
- 종료 원인·정확한 경기 시간·최종 구역 단계를 결과 화면과 로컬 기록에 보존한다. 결과 저장이 이전 페이즈의 React 상태를 읽더라도 실제 종료 시간/날짜를 사용한다.
- 최종 구역 상태를 화면에 복사해 전달한다. 미니맵의 Set 개수 오류, 안전지역까지 위험하다고 추정하던 배지/상단 경고/로그를 수정했다. 지도·체력·장비 전체의 진행 중 동기화는 별도 후속 작업이다.

- 네 경기 모두 전지역 폐쇄 전에 실제 교전으로 끝났다. 강제 점수 판정/집결 이벤트 없음, 게스트 API 요청 0.
- 시간 순서, 사망 후 같은 페이즈 재행동, 중복 행동/타격, 공유 자원 보존 검사를 유지했다.
- 일반 이동과 최종 구역 이동의 경로·시간 비용도 검사한다. 전투 도주/추격은 별도 회복 잠금을 사용하므로 일반 이동 ETA 필드와 혼동하지 않는다.
- 솔로 경기 팀 어시스트 0 확인.
- 난수 지정 예: PowerShell에서 `$env:EH_MATCH_SEED='2202'; node scripts/check-action-timeline.mjs`. 솔로는 별도 프로세스에 `$env:EH_MATCH_MODE='solo'`도 지정한다.

## 남은 검증

- 위 네 경기는 기본 로스터의 제한된 기준선이다. 폭넓은 편성·전략·사용자 지도·난수에서의 생존 편향과 종료 원인 분포를 입증하지 않는다.
- 이동/교전이 중후반까지 이어진다는 기능 증거이지, 재미 또는 재플레이 욕구의 합격 판정이 아니다.
- G4 관측 결함: 2일 밤 06:35에 부활 로그가 나온 상태에서 화면은 생존 20/사망 0을 표시했다. 진행 중 생존자/부활자 상태 전달이 일관되지 않으며, 이번 금지구역 표시 수정으로 해결됐다고 취급하지 않는다.
- 일반 진행 중 체력/장비/팀 위치 동기화, 팀 추적·의사결정 설명, 저장 입력 재현과 실제 사용자 평가는 남아 있다. 전체 목표는 미완료다.
