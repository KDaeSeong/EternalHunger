# 문명 아카이브 후계 인물 표시

파티 선택 카드와 창건자·전승 화면에서 현재 인물의 세대·역할·생애 상태·실제 지도자·본인 특성을 함께 보여 준다. 준비 후계는 일일과 연간 모드 모두 표시하며, 은퇴·사망한 인물에도 같은 계보 설명을 사용한다. 기존 선택·후계 준비·은퇴 확인·취소·가호 행동은 유지한다.

## 본인과 계보 참고의 구분

인물 본인의 기존 초상과 사용자 지정 그림은 그대로 사용한다. 생성된 후계에게 창건자 그림을 본인 얼굴로 대입하지 않는다. 별도의 24픽셀 참고 그림에 **계보의 창건자 · 이름**을 붙인다. 첫 선택 인물이 아닌 계보의 시작 인물은 **계보 시작 인물 · 이름**으로 구분한다. 대체 텍스트도 현재 후계의 초상이 아님을 설명한다.

역할은 기존 정찰·사냥·제작·지원 텍스트와 등록된 행동 아이콘, 시대별 색을 함께 사용한다. 미상 역할은 중립 표시이며 색만으로 구분하지 않는다. 새로운 그림이나 원작 설정을 생성하지 않는다.

## 기록에 근거한 표시

새 `archiveIdentityIndex(state)`는 현재 런의 계보와 생애 기록을 각각 한 번 검증하고 식별자별 표시 자료를 만든다. 화면은 상태가 바뀔 때 이 조회를 한 번 수행한다. 게임 상태를 정규화·수정하거나 새 인물을 만들지 않는다.

후계의 세대와 기준 인물은 실제 계보의 `founderId`·`generation` 및 준비 후계의 `lineageRootId`·`lineageGeneration`을 교차 확인한다. 지도자는 준비 기록의 `mentorId` 또는 유일한 직전 인물의 `successorId` 연결로만 표시한다. 이 관계는 공동체의 인계 관계이며 생물학적 부모·친자 관계가 아니다.

세대 0만으로 창건자라고 부르지 않는다. 현재 런의 유효한 생애 기록에 `isFounder: true`가 있어야 창건자 표시를 한다. 기존 계보가 없거나 중복·다른 런·모순·표현 가능한 정수 범위 밖의 세대가 있으면 해당 관계를 추정하지 않는다. 생애 기록에 독립적으로 확인된 창건 여부와 세대 기록 유무는 서로 구분한다.

조회 결과는 읽기 전용이다. 원본 초상화 해석기와 게임 엔진·후계·달력·생애·저장 구조, 수치와 보상은 바꾸지 않는다. 조상의 가호나 전승을 후계의 고유 능력으로 새로 부여하거나 설명하지 않는다.

## 검증 범위

`npm run check:primitive-archive:identity`는 현재 추적 소스와 새 고정 입력만 사용하는 두 검사를 실행한다. 기존 엔진으로 만든 실제 준비·인계·여러 세대·자연사 상태를 사용하며, 사설 원본이나 과거 경기 결과가 일반 검사에 필요하지 않다. 원본 상태의 불변성, 난수·시각·저장소 접근 없음, 사용자 초상 보존과 잘못된 기록도 검사한다.

화면 검사는 실제 구성 요소의 정적 렌더와 제어한 훅·콜백으로 인물 선택과 은퇴 확인 보호, 준비·과거 인물 표시, 본인·참고 초상 구분을 다룬다. 기존 두 화면의 원본 소스에서 새 후계 표시가 없음을 확인하는 대조는 별도의 사설 일회성 검사이다.

전체 검사·빌드·공개 전달은 별도의 실행 결과로 판정한다. 정적 렌더와 제어한 콜백은 실제 브라우저의 키보드·좁은 화면·탑재 수명주기 검증이나 사람의 플레이 평가를 대신하지 않는다. 현재 실제 화면 조작 중단 상태는 유지하며, 전체 시대 운영과 원래의 다중 게임 목표도 완료로 표시하지 않는다.
