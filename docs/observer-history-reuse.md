# 관전 사건 구간의 계산 재사용

팀 관전은 같은 사건 창에서 화면 시각이나 현재 인물 상태만 바뀌어도 사건의 임시 행과 판단·합류·조달 연결을 다시 만들었다. 이번 변경은 소유된 불변 사건 창의 시간순 참조와 **직전 조회 구간의 연결 상태 한 벌**을 재사용한다. 게임 규칙·사건·로그·난수·최종 결과를 줄이거나 생략하지 않는다.

## 실제 전달 경로와 계측 범위

작업 스레드의 사건 메시지는 즉시 처리하고, 화면 프레임과 보이는 기록은 각각 별도의 화면 갱신 예약으로 게시한다. 따라서 기록 시각이 현재 화면보다 앞서는 중간 상태가 가능하다. 실제 빈도와 성능 기여율을 소스만으로 확정하지 않는다.

기존 관전용 `runEvents`는 최대 5,000건이며 전체 기록은 별도의 FIFO 장부에 보존한다. 이 한도와 게시 방식을 변경하지 않는다. 계측에는 현재 소스와 새 고정 사건을 사용하며 과거 경기 결과를 새 실행의 입력으로 재사용하지 않는다.

정상 체력 관측이 있는 통제 입력 5,000건 중 선택 팀 관련 기록 4,000건의 미래 사건 없는 재조회에서는 기존 행 구성·연결 처리 4,000회와 조달 갱신 1,000회가 반복됐다. 설명 생성은 27회로 이미 제한되어 있었다. 수정 후 동일 구간 재조회는 앞선 세 처리가 0회이고 설명 생성은 27회로 유지된다. 시각 구간이 바뀌면 해당 전체 연결 처리를 다시 수행한다. 이는 통제된 함수 실행 횟수이며 실제 브라우저 배속이나 전체 CPU 개선률이 아니다.

## 보존하는 계약

공개 사건 창의 `eventsRef`·`memberKey`·원래 순서의 `rows`와 각 행의 원본 사건 참조·번호·시각·동결 상태는 유지한다. 비정렬 기록은 별도의 시간순 참조를 한 번 만들고 동일 시각은 원래 번호로 정렬한다. 공개 행에 판단 연결 필드를 추가하지 않는다.

숫자 시각은 이진 검색으로 포함되는 구간을 찾는다. 같은 끝 위치이면 연결 상태를 재사용하며, 구간 변경과 과거 조회에서는 다시 계산하고 직전 한 벌만 교체한다. 여러 과거 구간이나 다른 인물 상태를 누적 보관하지 않는다. `NaN`·무한대·음의 0 및 숫자 외 시각의 원래 비교·형 변환 의미를 유지한다. 다른 사건 배열·다른 인물 집합·위조된 창은 기존 기본 계산으로 돌아간다.

이름·지역명·체력·장비·성장·목표 경쟁·현재 상태는 매번 현재 인물로 계산한다. 반환된 팀·인물·목표의 기존 입력 참조는 보존한다. 조달 결과는 최상위 사본으로 내보내 결과 필드 교체가 내부 기록을 오염시키지 않게 하되, 기존에 허용되던 중첩 입력 객체·배열 참조는 바꾸지 않는다. 소유된 사건이 수정됐으면 기존 계약대로 기본 계산을 쓰거나 창을 다시 만든다.

새 약한 참조 저장소는 불변 사건 창에만 적용한다. 상태·연구 정규화용 캐시나 인물 상태 캐시는 추가하지 않는다. 보관량은 현재 창의 행 수에 비례한다. 소스의 보관 구조 확인과 실제 브라우저 메모리 회수 검증은 별개의 근거이다.

## 검증 경계

일반 `check:observer-history-reuse`는 현재 소스만 사용해 전체 모델·원래 참조·정렬·과거 조회·창 격리·조회 순수성과 같은 구간 재사용을 검사한다. 사설 원본 파일은 필요하지 않다. 기존 팀 관전 묶음에도 포함된다.

별도의 명시적 사설 대조는 변경 전 원본 모듈과 현재 모듈이 각자 만든 창을 사용한다. 정상·이전 체력 기록, 작은 입력과 5,000건, 낮고 높은 팀 비율, 동일 시각·비정렬·미래·과거 조회를 포함한 576조건과 중첩 입력 참조 8조건을 대조했다. 원본과 현재의 전체 출력·순서·원본 참조·입력 보존·난수 호출 0을 확인했다. 최초 통제 입력의 한계와 참조 회귀 실패도 덮어쓰지 않고 별도로 보존한다.

공식 전체 체인의 빌드 앞 29명령과 공통 피드백·공통 화면·변경 소스 린트를 합한 32명령이 모두 종료 0이다. 같은 선언 소스 1,300개로 최종 빌드 `H6ArT0a74-Q55uovna8Mw`와 격리된 Node VM 작업자의 첫 구간 실행이 통과했다. 일반 집중 검사의 사설 입력 차단 실행도 별도로 통과했다. 공개 전달은 이 빌드와 공개 페이지·관전 청크·작업자 의존 파일의 실제 비교 결과로 판정한다.

관전 파일도 버전 해시 대상이므로 새 해시 `3102c32c…`를 생성했다. 기존 `90deb53d…` 편성 8회는 그 버전의 역사 증거이며 `comparisonComplete=false`를 유지한다. 새 버전의 편성 비교나 엄격한 전경 9회가 완료됐다고 승계하지 않는다. 실제 화면은 Esc 중단 상태이며 원래 G1~G5·다른 게임·사람 평가·자연 로그인 만료 관문은 그대로 남는다.
