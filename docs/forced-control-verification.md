# 공포·매혹·도발의 실제 행동 연결

기준일: 2026-09-05. G2.3의 강제 행동 단계이며 전체 목표 완료가 아니다. 사용자 제공 상태 설명을 기준으로 실제 이동·공격·시전·성장 경로를 연결한다. 원작의 모든 CC/실험체/지형 구현을 인증하는 문서는 아니다.

후속 수면·변이·제압·경직 단계는 `action-states-verification.md` 참조. 아래 강제 행동 엔진의 완료 증거와 후속 엔진의 검증을 구분한다.

## 처리 범위

| 상태 | 실제 처리 |
| --- | --- |
| 공포 | 시전자로부터 멀어지는 방향으로 이동 속도만큼 보행한다. 스킬과 자율 파밍·이동·엄호를 중단한다. |
| 매혹 | 시전자 위치로 이동 속도만큼 보행한다. 기본 공격·스킬과 자율 행동을 중단한다. 순간이동으로 처리하지 않는다. |
| 도발 | 지정된 시전자에게만 기본 공격한다. 사거리 밖이면 접근하고, 안이면 기존 공격 속도의 간격을 지킨다. 팀 집중 표적이나 기존 교전 상대가 이를 덮어쓰지 않는다. |
| 속박/행동 불가 중첩 | 속박은 강제 보행도 막지만 사거리 안 도발 기본 공격까지 막지 않는다. 기절 등의 전체 행동 제한은 보행과 공격 모두 막는다. |
| 면역·저지 불가·정화 | 기존 실제 보호 판정을 공유한다. 무시 중인 명령은 작동하지 않고, 보호가 끝나도 시간이 남은 효과만 재개한다. 정화는 보관된 효과까지 제거한다. |
| 시전·성장·생명주기 | 새 강제 상태가 이미 진행 중인 캐릭터 시전을 취소한다. 금지구역에서도 파밍/자율 이동을 끼워 넣지 않는다. 사망·부활·새 편성에서 이전 제어 메모리를 정리한다. |

시전자 참가자 ID인 `sourceActorId`는 스킬 출처 `sourceId`와 별개다. 적용 시 참가자와 좌표를 값으로 복사하고, 효과 묶음·사건·JSON 저장/복원에도 보존한다. 이름이나 스킬 ID로 시전자를 추측하지 않는다.

## 프로젝트 규칙과 원작 확인 경계

- 제공 자료에 없는 동시 제어 우선순위는 **가장 나중에 적용/갱신된 강제 명령 우선**으로 정했다. 기존 명령은 시간이 흐르며, 우선 명령 종료 때 시간이 남아 있으면 재개한다. 일반 기절·속박 같은 별도 행동 제한을 무효화하는 규칙은 아니다.
- 제공된 공포 설명에는 기본 공격 허용 여부가 명시되어 있지 않다. 현재 제어기는 공포·매혹 중 자율 기본 공격을 하지 않고, 도발만 지정 기본 공격을 허용한다. 이 선택을 원작의 확인된 평타 규칙이라고 주장하지 않는다.
- 동일 상태 갱신은 기존 상태 시스템의 최대 잔여 시간 규칙을 사용하되 시전자·제어 순서는 마지막 적용을 따른다. 저항 감소는 새 시간에 한 번만 적용한다.
- 지역은 기존 24m 정사각형 추상 공간이다. 공포는 반대 방향의 직선을 따라 첫 경계에서 멈춘다. 경계 밖 새 지역으로 넘어가거나 벽을 통과하는 원작 이동기를 구현한 것은 아니다. 시전자와 같은 좌표면 난수를 쓰지 않고 +X 방향을 사용한다.
- 시전자의 최신 위치는 현재 구현된 개인/팀 시야에서 관측할 수 있을 때만 추적한다. 관측할 수 없거나 시전자가 사망/지역 이탈하면 마지막 관측/적용 위치를 사용하며, 위치가 전혀 없으면 대기한다. 다른 지역의 좌표는 재사용하지 않는다. 도발은 실제 살아 있는 적 시전자가 관측 가능하고 대상 지정 가능할 때만 공격한다. 위장·은신 등 아직 없는 시야 효과를 구현했다고 간주하지 않는다.
- 이동은 0.25초 경계와 상태 만료 경계에서 같은 사전 상태로 계산한다. 기존 이동/행동/회복 잠금도 존중한다. 일괄/분할 처리, 이동하는 시전자, 참가자 순서 변경과 JSON 복원을 통제 검사로 확인한다.
- 일반 게스트 명단에 원작 Q/W/E/R 또는 새 강제 상태 발생기를 자동 추가하지 않았다. 사용자 스킬에서 상태 부여·보호·정화를 편집하는 경로는 다음 잔여 작업이다. 통제 입력으로 확인한 효과를 기본 명단의 자연 발생 증거로 세지 않는다.

## 실패 재현 및 수정

1. 공포 중 스킬 사용이 허용되던 상태 이름/행동 판정 분리를 실제 제어 태그와 연결했다.
2. 1.5초 통제 구간의 전투 시계는 101.5초인데 공유 시간 실행기는 구간 길이를 정수로 잘라 이동을 101초에서 멈췄다. 실제 누적 경과 시간이 1초인 실패를 독립 검사로 재현한 뒤 소수 구간을 보존했다. 매혹 x=8→13.25(1.5초 × 3.5m/s)를 확인했다. 기본 정수 페이즈에서 항상 이 오류가 발생했다는 뜻은 아니다.
3. 공포 뒤 도발을 적용해도 이전 공포의 기본 공격 차단 태그가 도발 공격을 막았다. 선택된 강제 명령만 해당 평타 제한을 결정하도록 수정하고, 도발 종료 후 남은 공포 재개까지 실제 공격/이동 검사로 확인했다.
4. 공포 목적지의 X/Y를 각각 경계로 자르면 대각선 방향이 모서리 쪽으로 변했다. 반대 방향 직선과 첫 경계의 교점으로 바꾸고 (4,8) 대 (8,10)에서 방향과 (0,6) 정지를 검사했다.
5. 관전창의 강제 이동/표적/종료 이유를 추가했다. 실제 화면에서 사거리 안 도발도 접근 중처럼 설명하는 것을 확인하고 `사거리 안 · 시전자 기본 공격 대기`로 구분했다.

## 계속 남은 범위

수면·변이·제압·경직/목걸이 정지는 후속 `action-states-verification.md`에서 구현·검증 중이다. 나머지 시야 상태, 사용자 스킬 상태 편집, 고유 자원/쿨다운과 특수 경로를 이어간다. G1~G3 전체 지급 감사·파밍/합류/생존 균형, G5.2 전략 비교, G5.3 실제 경험자의 이해·재미·재플레이 평가는 여전히 미완료다.
