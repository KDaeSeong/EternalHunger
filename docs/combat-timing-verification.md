# 공격 속도·전투 시간축 구현과 검증

기준일: 2026-09-05. G2.3의 실제 기본 공격 간격을 구현한 단계다. 원작 최신 수치 전체 복제, 스킬 시전 전체 재현, 밸런스·재미 합격을 뜻하지 않는다.

후속 기록: 독립 캐릭터 시전/발동/취소는 이후 `character-casting-verification.md` 단계에서 구현했다. 아래 엔진 버전·경기 수치와 당시 남은 범위는 공격 간격 단계의 기록으로 보존하며, 현재 시전 구조의 설명으로 재사용하지 않는다.

공간 후속 기록: 실제 좌표·접근·시야·사거리와 최신 전체 회귀/브라우저 재경기 증거는 `combat-spatial-verification.md`에 기록했다. 거리 연결 자체를 현재 미구현 항목으로 세지 않는다.

## 변경 이유와 현재 규칙

이전 경로는 참가자 순번마다 세계 시간을 진행하고, 교전 시 각 참가자에게 공통 8초 행동 잠금을 부여했다. 공격 속도가 실제 초당 타격 횟수로 이어지지 않았고, 참가자가 많으면 자기 차례도 늦어졌다.

- 교전 발견을 위한 기존 순번과, 이미 시작된 교전의 다음 공격 시각을 분리했다. 새 교전을 찾는 AI 탐색은 여전히 기본 1초 순번이다. 모든 AI 판단을 연속 시간으로 바꿨다는 뜻은 아니다.
- 참가자의 최종 계산 공격 속도를 사용하여 `다음 공격 = 현재 시각 + 1 / 공격 속도`를 예약한다. 기존 프로젝트 능력치 상한을 최종 장비 적용 후에도 유지하여 0.1~3회/초로 제한한다. 이 상한은 프로젝트 규칙이며 원작 최신 상한 확인 결과가 아니다.
- 시간 정밀도는 소수점 여섯 자리다. 예를 들어 공격 속도 2는 0.5초, 0.5는 2초, 0.72는 1.388889초 간격이다.
- 속도 변화는 다음 공격이 새 간격을 예약할 때 반영한다. 이미 예약한 간격을 소급하여 단축하거나 밀린 공격을 적립하지 않는다.
- 기본 공격의 공통 8초 잠금을 제거했다. 같은 순간 중복 호출은 개인 공격 타이머로 거절한다. 엄호는 별도 행동이므로 기존 8초 비용을 유지한다.
- 기절·대상 지정 불가 해제 시각과 기존 이동/스킬 행동 잠금을 함께 고려한다. 0.25초 기절을 다음 정수 초까지 연장하지 않는다. 사망·지역 이탈·회복 이탈로 무효가 된 교전은 이어 때리지 않는다.
- 현재 지역의 살아 있는 상대와 교전 중이면 일반 성장 기회를 동시에 사용하지 않는다. 금지구역 탈출 판단은 별도 허용하며 다른 행동 제한은 유지한다.
- 전투 의도와 공격 예약은 참가자 상태에 남아 다음 페이즈 및 JSON 상태 보존에 포함된다. 일반 전투 정리로 살아 있는 참가자의 다음 공격을 초기화하지 않는다. 부활한 새 생명만 과거 공격 예약을 지운다.

## 다른 시계와의 연결

- 20초 성장 경계는 한 번만 실행한다. 공격이 1초 사이를 나누어도 스폰·부활·에너지·정산을 추가로 지급하지 않는다.
- 상태 지속 시간, 지속 피해/재생, 금지구역 타이머·보호 시간, 쿨다운에서 소수점 경과 시간을 보존한다. 상태 만료 경계는 나누어 처리하여 치유 감소 종료 전후의 회복량이 주변 공격 빈도에 따라 달라지지 않도록 했다.
- 앞선 상태 구간에서 죽은 참가자가 뒤의 재생 구간으로 되살아나는 것을 막았다.
- 마지막 사망·경기 종료 사건·최종 표시 상태는 동일한 여섯 자리 시간값을 사용한다.
- 화면 대기는 사건 개수가 아니라 실제 경과 시간과 배속에 비례한다. 같은 시각의 추가 사건에는 대기를 더하지 않는다. 밀리초 대기 반올림과 실제 렌더링 비용 때문에 현실 경과 시간까지 정확히 일치한다는 보장은 아니다.
- 1초 미만의 활성 상태를 `0초`로 표시하지 않는다. 표시만 소수 둘째 자리까지 올림하며 실제 상태 시간을 바꾸지 않는다.

## 통제 검사

`client`에서 `cmd /c npm run check:combat-timing`: **26/26 통과**. 전체 `check:eternal-hunger`에도 연결했다.

- 실제 PvP 실행기·실제 피해 적용: 6초 교전에서 속도 2는 12회, 속도 0.5는 3회 타격한다. 1 피해 시험에서 상대 HP 감소는 각각 12/3이다.
- 실제 3대3: 여섯 참가자가 자기 간격대로 총 42회 공격한다. 원격 참가자 22명을 추가해도 이미 시작된 1대1의 공격 시각은 같다.
- 비정수 간격, 장비·상태 속도 및 만료, 도중 속도 변화 정책, 중복 호출·실명 헛공격의 시간 소비를 검사한다.
- 기절 뒤 몰아치기 금지, 0.25초 상태 해제, 대상 지정 재허용, 이동·시전/후딜 예약 우선, 지역 이탈·사망 뒤 공격 금지를 검사한다.
- JSON 공격 예약 보존, 부활/일반 정리 구분, 교전 중 무료 성장 금지, 부분 보호·폭발 경계, 상태 분할 계산, 치유 감소 만료, 재생 부활 금지를 검사한다.
- 성장 중복 없음, 0초/0.25초 잠금, 실제 경과 시간만큼 표시 대기, 소수점 상태 문구를 검사한다.

기존 팀 교전 검사는 공통 8초 잠금 기대값을 개인 공격 타이머 검사로 교체하고 같은 시각의 재공격 금지 검사를 유지했다. 시간축/난수 검사의 대기 횟수는 실제 표시 경과 초의 합계로 바꾸어 종료 시각과 정확히 일치해야 한다. 검사 기준을 없애거나 종료·긴 기록 요건을 낮추지 않았다.

## 남은 범위

- 캐릭터 스킬은 아직 기본 공격 때 평가하여 피해를 즉시 적용하고, 시전/후딜 중 최대 행동 잠금을 예약하는 구조다. 스킬을 별도로 선택하여 순차 시전하고 발동 시점에 피해를 적용하거나 중간에 취소하는 구조는 다음 작업이다. 이번 검사는 잠금 준수만 증명한다.
- 구역 내부 실제 거리, 기본 공격 사거리, 시야, 접근/추적 이동, 투사체는 미구현이다. 현재 같은 지역 조건은 실제 미터 거리 판정이 아니다.
- 전체 CC/면역 종류, 방해 효과 저항의 지속 시간 감소, 고정 공격 속도 실험체, 고유 자원, 각 쿨다운 감소 종류와 예외는 추가 작업이다.
- 야생동물·차원의 틈·추격 등 별도 전투 및 특수 효과 경로는 아직 공통 시간축/피해 규칙 감사 대상이다.
- 지속 피해로 HP가 0에 이르는 수학적 순간이나 긴급 가젯의 임계점까지 모든 세계 사건을 별도로 예약한 것은 아니다. 세계 경과 처리는 정수 초 및 예약된 교전 경계를 사용한다. 상태/장비 변화가 기예약 공격 간격을 소급 변경하지 않는 정책도 유지한다.
- 새 버전으로 폭넓은 편성/난수의 성장·합류·후퇴 반복·종료 분포를 다시 측정해야 한다. G5.2 재편성/전략 비교 및 G5.3 실제 사용자 평가는 남아 있다.

이 단계에서는 브라우저를 새로 조작하지 않았다. 자동 실행기와 표시 문구 검사를 실제 브라우저 상태 연출·성능 또는 사용자 재미 평가로 부르지 않는다. 전체 목표는 계속 미완료다.
